## Integration Findings

### 1. TracingObserver Excluded from CompositeObserver *(tech debt)*

**Affected:** TRAC-01, COMP-01
**Location:** `src/observer/tracing_observer.rs`

`TracingObserver` implements only `GaObserver<U>`. `CompositeObserver` stores `Vec<Arc<dyn AllObserver<U>>>` where `AllObserver<U>` requires all three observer traits. Missing:
```rust
impl<U: ChromosomeT> IslandGaObserver<U> for TracingObserver {}
impl<U: ChromosomeT> Nsga2Observer<U> for TracingObserver {}
```

`MetricsObserver` correctly has these empty impls (metrics_observer.rs lines 120-122). `TracingObserver` does not.

**Fix:** Add two empty `impl` blocks to `src/observer/tracing_observer.rs` (same pattern as MetricsObserver).

---

### 2. Hook Ordering Inversion: on_extension_triggered Fires After on_generation_end *(tech debt)*

**Affected:** LOG-01, OBS-01
**Location:** `src/ga.rs` lines 964–984

Pre-v2.2.0 execution order: extension block → stats/best-chromosome block (extension log before "best chromosome" log).
Current v2.2.0 order: `on_generation_end` (line 965) → extension runs → `on_extension_triggered` (line 979).

LogObserver users who relied on pre-v2.2.0 log ordering will see extension events after generation-end events. `on_extension_triggered` is a low-frequency event (only when diversity < threshold), so real-world impact is small — but it breaks the strict LOG-01 "identical output" guarantee.

**Fix:** Move the extension block in `ga.rs` before the stats-collection/`on_generation_end` call, or document the ordering change in the migration guide.

---

### 3. Duration::ZERO in Mutation and Fitness-Eval Hooks *(tech debt)*

**Affected:** OBS-01, TRAC-01, COMP-02
**Location:** `src/ga.rs` lines 785–786

```rust
self.notify(|obs| obs.on_mutation_complete(i, Duration::ZERO, pop_size));
self.notify(|obs| obs.on_fitness_evaluation_complete(i, Duration::ZERO, pop_size));
```

Selection and survivor hooks correctly gate `Instant::now()` on `self.observer.is_some()`. Mutation and fitness-eval hooks do not. MetricsObserver histograms `ga.operator.mutation_ms` and `ga.operator.fitness_eval_ms` always record 0. TracingObserver emits zero-duration spans for these operators.

**Fix:** Add observer-gated `Instant::now()` before the crossover/mutation block in `ga.rs` (same pattern as selection timing at lines ~730-733).

---

### 4. NoopObserver Not Re-exported from lib.rs *(ergonomics)*

**Affected:** OBS-02
**Location:** `src/lib.rs`

All other observer types are re-exported at crate root. `NoopObserver` (defined in `src/observer/mod.rs:95`) is absent. Users must use `genetic_algorithms::observer::NoopObserver`.

**Fix:** Add `pub use observer::NoopObserver;` to `src/lib.rs`.

---

### 5. ExtensionEvent and TerminationCause Not Re-exported *(ergonomics)*

**Affected:** OBS-01
**Location:** `src/lib.rs`

Custom observer implementations need to match on `TerminationCause` in `on_run_end` and inspect `ExtensionEvent` in `on_extension_triggered`. Neither type is re-exported from the crate root.

**Fix:** Add to `src/lib.rs`:
```rust
pub use observer::ExtensionEvent;
pub use ga::TerminationCause;
```
