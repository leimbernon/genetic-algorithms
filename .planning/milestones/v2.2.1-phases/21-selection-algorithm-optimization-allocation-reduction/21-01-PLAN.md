    .min(n - 1);

In `src/operations/selection/boltzmann.rs`, replace line 94:
```rust
let idx = cumulative.iter().position(|&cp| cp >= r).unwrap_or(n - 1);
selected.push(idx);
```
with:
```rust
let idx = cumulative.partition_point(|&cp| cp < r).min(n - 1);
selected.push(idx);
```

IMPORTANT: `partition_point` is called directly on the Vec/slice, NOT on `.iter()`. The predicate receives `&(usize, f64)` or `&f64` by reference. The predicate MUST be `cp < r` (not `cp <= r` or `cp > r`) because `partition_point` returns the first index where the predicate is false, which gives us the first index where `cp >= r`.

The `.min(n - 1)` clamp is essential because `partition_point` can return `n` when all cumulative values satisfy the predicate (float drift edge case), which would cause an index-out-of-bounds panic.

Also remove the comment `// Find the first individual whose cumulative probability >= r` in rank.rs since the code is now self-documenting via partition_point.
