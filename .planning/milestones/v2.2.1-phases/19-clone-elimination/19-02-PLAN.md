<objective>
Eliminate redundant full-DNA Vec allocations in all five numeric mutation operators by replacing the `dna().to_vec()` + clone + `set_dna()` pattern with direct `set_gene()` calls.

Purpose: Each numeric mutation modifies exactly ONE gene. Allocating a full Vec copy of the entire DNA to change one gene is wasteful. `set_gene()` edits in-place via `dna_mut()`.
Output: Five modified mutation operator files, each using `individual.dna()[idx].clone()` + modify + `individual.set_gene(idx, gene)` instead of `individual.dna().to_vec()`.
</objective>

pub trait ChromosomeT: Clone + Default + Send + Sync + 'static {
    type Gene: GeneT;
