<objective>
Eliminate redundant full-parent clones in all crossover operators by constructing children via `U::new()` + `set_dna()` instead of `parent.clone()` + `set_dna()`.

Purpose: Every crossover operator currently clones both parent chromosomes (fitness function, metadata, DNA, age) just to immediately overwrite the DNA. Children only need fresh default state plus computed DNA. `U::new()` avoids cloning the fitness function closure, age counter, and other parent metadata.
Output: Ten modified crossover operator files, each using `U::new()` for child construction.
</objective>

```rust
pub trait ChromosomeT: Clone + Default + Send + Sync + 'static {
    type Gene: GeneT;

    fn new() -> Self {
        Default::default()
    }

    fn set_dna<'a>(&mut self, dna: Cow<'a, [Self::Gene]>) -> &mut Self;
    fn set_age(&mut self, age: usize) -> &mut Self;
    fn dna(&self) -> &[Self::Gene];
}
```

Per CONTEXT.md decisions:
- Children MUST be built from `U::new()` + `set_dna(Cow::Owned(dna))` — NOT `parent.clone()` + `set_dna()`
- Children start with default state: `fitness = 0.0` (actually NaN from Default), `age = 0`
- Children should NOT inherit any parent metadata beyond DNA
- This is correct because fitness is always re-evaluated before selection
