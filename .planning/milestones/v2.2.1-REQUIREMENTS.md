## v2.2.1 Requirements

All 24 requirements are internal optimizations. No public API changes.

### Clone Elimination

- [x] **CLONE-01**: GA engine defers parent clones in `parent_crossover()` until actually needed as fallback children
- [x] **CLONE-02**: Crossover operators (MultiPoint, Uniform, Cycle, SinglePoint) build children directly without cloning full parent chromosomes
- [x] **CLONE-03**: Numeric mutation operators (Value, Creep, Gaussian, Polynomial, NonUniform) use `set_gene()`/`dna_mut()` instead of `dna().to_vec()`
- [x] **CLONE-04**: Swap, Inversion, and Scramble mutations use in-place operations without per-gene clones

### Allocation Reduction

- [x] **ALLOC-01**: Fitness values collected once per generation and reused across extension, niching, and stats (eliminates 2 redundant O(n) allocations)
- [x] **ALLOC-02**: Niching distance matrix computed on-the-fly instead of full O(n²) memory allocation

### Algorithm Optimization

- [x] **ALGO-01**: Order Crossover (OX) uses a pre-built position map for O(n) lookup instead of O(n²) linear search — *Satisfied by commit ca5bb76 (Task 4.8): HashSet membership check replaces Vec::contains, making OX O(n). No Phase 20 code change needed.*
- [x] **ALGO-02**: PMX Crossover uses a pre-built position map for O(n) lookup instead of O(n²) linear search
- [x] **ALGO-03**: Rank Selection uses `partition_point()` binary search instead of O(M×N) linear scan
- [x] **ALGO-04**: Boltzmann Selection uses binary search and single-pass cumulative probability computation
- [x] **ALGO-05**: Elite reinsertion uses `select_nth_unstable_by()` O(n) instead of full O(n log n) sort
- [x] **ALGO-06**: Mass Genesis finds 2 best chromosomes in O(n) with two linear passes instead of a full sort

### Concurrency

- [x] **CONC-01**: RNG atomic ordering relaxed from `SeqCst` to `Acquire`/`Relaxed` for seed/counter respectively
- [x] **CONC-02**: Extension population regrow parallelized with rayon (matching parallel crossover/mutation pattern)

### Memory Layout

- [x] **MEM-01**: `Range` genes use `Arc<[(T, T)]>` shared range slice, eliminating per-gene heap allocations
- [x] **MEM-02**: `Range::value()` returns by value for `Copy` types without calling `.clone()`
- [x] **MEM-03**: Unused `generation_numbers` field removed from `Population`
- [x] **MEM-04**: `FitnessFnWrapper::call()` annotated with `#[inline]`
- [x] **MEM-05**: Mass Deduplication uses incremental `DefaultHasher` instead of allocating `Vec<i32>` per chromosome

### Minor Improvements

- [x] **MISC-01**: `GenerationStats` moved (not cloned) when pushed to stats vec
- [x] **MISC-02**: Truncation Selection uses `select_nth_unstable()` for O(n) partitioning
- [x] **MISC-03**: Best chromosome scan deduplicated — `fitness_calculation()` result reused, no redundant rescan
- [x] **MISC-04**: Island migration selection/replacement uses `select_nth_unstable()` instead of O(n log n) sort
- [x] **MISC-05**: Island migration avoids cloning migrant vectors per neighbor topology
