- **src/fitness.rs**: "Fitness — fitness function wrapper. Wraps user-provided fitness functions with caching and evaluation tracking. Supports both single-objective (f64) and multi-objective (Vec<f64>) fitness evaluation."

- **src/population.rs**: "Population — chromosome container. Holds the population of candidate solutions with accessors for best chromosome, fitness statistics, and iteration. Used by all engines as the primary solution container."

- **src/stats.rs**: "Stats — per-generation statistics. Tracks fitness (best, average, median, worst), diversity, generation duration, and convergence metrics. Accessible during and after the GA run."

- **src/checkpoint.rs**: "Checkpoint — serialization support (serde feature). Enables saving and restoring GA state to resume interrupted runs or share configurations. Requires the `serde` feature flag."

- **src/rng.rs**: "RNG — random number generation utilities. Provides seeded or unseeded RNG via the `rand` crate. Use set_seed() for reproducible runs."

- **src/validators/**: "Validators — configuration validation. Validates GA configuration before run() to catch errors early. Checks population sizes, operator compatibility, and parameter bounds."

- **src/visualization.rs**: "Visualization — plotting utilities for Gnuplot-based charts. Provides plot_fitness(), plot_diversity(), and plot_histogram() for post-run analysis."

**For struct/enum/trait definitions:**
```rust
/// [One-line description of what this type represents].
///
/// [Additional context if needed — when to use, key behavior, constraints]
///
/// # Example
/// ```rust,ignore
/// // Brief usage example
/// ```
pub struct MyStruct { ... }
```

**For public functions/methods:**
```rust
/// [What this function does].
///
/// # Arguments
/// * `param_name` — [description]
///
/// # Returns
/// [description of return value]
///
/// # Panics
/// [if applicable: conditions under which this panics]
pub fn my_function(param: Type) -> ReturnType { ... }
```

**For public enum variants:**
```rust
/// [What this variant represents].
VariantName,
```

**For feature-gated items (benchmarks, serde):**
```rust
/// [Description].
///
/// Requires the `benchmarks` feature.
#[cfg(feature = "benchmarks")]
#[doc(cfg(feature = "benchmarks"))]
pub fn hypervolume(...) { ... }
```

**Prioritization:**
1. First pass: public structs, traits, enums (the user-facing API types)
2. Second pass: public functions and methods (the user-facing actions)
3. Third pass: public enum variants, type aliases, associated types

**Items to skip:**
- `pub mod` / `pub use` re-exports (they re-export items documented elsewhere)
- `pub(crate)` items (not part of the public API)
- `#[doc(hidden)]` items

**Critical constraint:** Do NOT change any code — only add doc comments. No API changes, no refactoring.
