    ```rust

    ```

    Replacement: import `ZDT1` and create a shared wrapper:
    ```rust
    use genetic_algorithms::benchmarks::ZDT1;
    
    let zdt1 = ZDT1::new(N_VARS);
    let obj_f1 = {
        let zdt1 = &zdt1;
        |dna: &[RangeGenotype<f64>]| -> f64 {
            let x: Vec<f64> = dna.iter().map(|g| g.value).collect();
            zdt1.evaluate(&x)[0]
        }
    };
    let obj_f2 = {
        let zdt1 = &zdt1;
        |dna: &[RangeGenotype<f64>]| -> f64 {
            let x: Vec<f64> = dna.iter().map(|g| g.value).collect();
            zdt1.evaluate(&x)[1]
        }
    };
    ```

    Note: These closures capture `zdt1` by reference, so use `{ let zdt1 = &zdt1; move |...| ... }` pattern to ensure the reference is moved into the closure, not the ZDT1 itself. Alternatively, define a helper function:
    ```rust
    fn evaluate_zdt1_f1(zdt1: &ZDT1, dna: &[RangeGenotype<f64>]) -> f64 {
        let x: Vec<f64> = dna.iter().map(|g| g.value).collect();
        zdt1.evaluate(&x)[0]
    }
    fn evaluate_zdt1_f2(zdt1: &ZDT1, dna: &[RangeGenotype<f64>]) -> f64 {
        let x: Vec<f64> = dna.iter().map(|g| g.value).collect();
        zdt1.evaluate(&x)[1]
    }
    ```
    Then in the closure:
    ```rust
    let obj_f1 = {
        let zdt1 = &zdt1;
        move |dna: &[RangeGenotype<f64>]| -> f64 { evaluate_zdt1_f1(zdt1, dna) }
    };
    ```

    Wait, the original closure pattern uses `|dna|` without `move`. But with the borrowed ZDT1, we need `move` closures that capture the reference. This works in Rust because the closures outlive the `zdt1` local only down to `.with_objective_fns()` call which is synchronous.

    Actually, the simplest approach: define a helper function in the example's scope:
    ```rust
    fn zdt1_f1(zdt1: &ZDT1, dna: &[RangeGenotype<f64>]) -> f64 {
        let x: Vec<f64> = dna.iter().map(|g| g.value).collect();
        zdt1.evaluate(&x)[0]
    }
    fn zdt1_f2(zdt1: &ZDT1, dna: &[RangeGenotype<f64>]) -> f64 {
        let x: Vec<f64> = dna.iter().map(|g| g.value).collect();
        zdt1.evaluate(&x)[1]
    }
    ```
    Then:
    ```rust
    let zdt1 = ZDT1::new(N_VARS);
    let obj_f1 = { let z = &zdt1; move |dna| zdt1_f1(z, dna) };
    let obj_f2 = { let z = &zdt1; move |dna| zdt1_f2(z, dna) };
    ```

    This preserves the exact same external behavior: the closures take `&[RangeGenotype<f64>]` and return `f64` for the two ZDT1 objectives. The mathematical result is identical (verified by per D-13).
