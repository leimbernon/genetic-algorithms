Create the file `src/hall_of_fame.rs` implementing the following types and methods.

**Types to define:**

1. `DistanceMetric` enum (per D-01, D-02):
   - `Fitness { min_distance: f64 }` -- Euclidean distance in fitness space (single-objective: `|f1 - f2|`)
   - `Genotypic { min_distance: f64 }` -- fraction of differing gene positions (by gene.id())
   - Default: `Fitness { min_distance: 0.0 }` per D-02
   - Derive: `Debug, Clone, Copy, PartialEq`
   - Conditional serde: `#[cfg_attr(feature = "serde", derive(serde::Serialize, serde::Deserialize))]`

2. `HallOfFameConfig` struct:
   - `capacity: usize` -- maximum number of archived solutions
   - `distance_metric: DistanceMetric` -- diversity filtering configuration
   - Default: capacity=100, distance_metric=Fitness { min_distance: 0.0 }
   - Derive: `Debug, Clone, PartialEq`
   - Conditional serde: `#[cfg_attr(feature = "serde", derive(serde::Serialize, serde::Deserialize))]`

3. `Entry<U>` struct (per D-11):
   - `pub chromosome: U` -- the archived chromosome
   - `pub generation_added: u64` -- generation number when added
   - `pub fitness_at_addition: f64` -- fitness value at time of addition
   - Bound: `U: ChromosomeT`
   - Derive: `Debug, Clone`
   - Conditional serde: `#[cfg_attr(feature = "serde", derive(serde::Serialize, serde::Deserialize))]`

4. `HallOfFame<U>` struct:
   - `entries: Vec<Entry<U>>` -- internal store, sorted by fitness descending (best first)
   - `capacity: usize`
   - `distance_metric: DistanceMetric`
   - Derive: `Debug, Clone`
   - Conditional serde: `#[cfg_attr(feature = "serde", derive(serde::Serialize, serde::Deserialize))]`
   - Bound: `U: ChromosomeT`

**Methods on `HallOfFame<U>` where `U: ChromosomeT`:**

5. `pub fn new(config: HallOfFameConfig) -> Self`:
   - Construct with given config, empty entries vec

6. `pub fn try_insert(&mut self, chromosome: &U, generation: u64) -> bool`:
   Per D-06, D-07:
   - Extract fitness via `chromosome.fitness()`
   - **Check 1 (fitness threshold per D-06):** If archive is full, requires `fitness >= self.entries.last().unwrap().fitness_at_addition` (last is worst since sorted descending). If not full, threshold passes.
   - **Check 2 (genotypic dedup per D-07):** Linear scan over entries, compare DNA slices via `gene.id()`. Use the same pattern from niching (ga.rs:1045-1056): iterate up to `max(dna.len(), existing_dna.len())`, treat missing positions as differing. If any entry has identical gene IDs in all positions, reject.
   - **Check 3 (distance filter per D-01):** If `DistanceMetric::Genotypic { min_distance }` and `min_dist > 0.0`, compute genotypic distance against all entries. If any is closer than `min_distance`, reject. If `DistanceMetric::Fitness`, distance check is a separate concern handled by insertion ordering (Fitness distance is implicit in fitness threshold).
   - **Insertion:** Binary search for position (descending fitness: higher fitness first). Use `binary_search_by` with `partial_cmp().unwrap_or(Equal).reverse()`. Insert the `Entry { chromosome: chromosome.clone(), generation_added: generation, fitness_at_addition: fitness }` at that position.
   - **Eviction (per D-04):** If `entries.len() > capacity`, call `entries.pop()` (removes worst/last).
   - Return `true` if admitted, `false` otherwise.

7. `pub fn solutions(&self) -> &[U]`:
   Return `&self.entries` -- but this returns `&[Entry<U>]`, not `&[U]`. Per D-10, `solutions()` should return the chromosomes. Since `Entry<U>` is not `U`, we need to return entries and let the caller map. Implement as returning `&[Entry<U>]` (the entries slice). The user request says `solutions() -> &[U]` but `Entry<U>` wraps chromosomes -- provide the raw entries slice. Add a `chromosomes()` method or document that `solutions()` returns entries.

   **Implementation decision:** Implement `solutions()` returning `&[Entry<U>]` (the entries sorted best-first) since that gives access to metadata. If the caller wants just chromosomes, they can use `iter().map(|e| &e.chromosome)`. Update the doc to reflect this.

8. `pub fn top(&self, k: usize) -> &[Entry<U>]`:
   - `&self.entries[..k.min(self.entries.len())]`

9. `pub fn would_qualify(&self, chromosome: &U) -> bool`:
   - If not full: `true`
   - If full: `chromosome.fitness() >= self.entries.last().unwrap().fitness_at_addition`

10. `pub fn len(&self) -> usize`:
    - `self.entries.len()`

11. `pub fn is_empty(&self) -> bool`:
    - `self.entries.is_empty()`

12. `pub fn iter(&self) -> impl Iterator<Item = &Entry<U>>`:
    - `self.entries.iter()`

13. `pub fn entries(&self) -> &[Entry<U>]`:
    - `&self.entries` -- raw access to the internal entries vec

**Free functions:**

14. `fn genotypic_distance<G: GeneT>(dna_a: &[G], dna_b: &[G]) -> f64`:
    - Count differing positions up to `max_len = max(dna_a.len(), dna_b.len())`
    - Missing positions count as differing (id = -1)
    - Return `diff as f64 / max_len as f64` (fraction, range [0, 1])
    - Pattern matches niching code at ga.rs:1045-1056

**Edge cases to handle:**
- NaN fitness: Skip insertion for chromosomes with `fitness.is_nan()` (prints a debug log via `log::debug!`)
- Empty DNA: Two chromosomes with empty DNA are considered identical
- Capacity=0: `try_insert` always returns `false` (no-op archive)
- All nan entries: archive stays empty

**Implementation notes:**
- Use `use std::cmp::Ordering;` for binary search comparison
- Use `use crate::traits::{ChromosomeT, GeneT};` for trait imports
- Serde conditional derive on all public types
- All methods are infallible -- no new `GaError` variant needed per RESEARCH.md
 - WASM-safe: pure data structure operations, no `Instant`, no `rayon`
