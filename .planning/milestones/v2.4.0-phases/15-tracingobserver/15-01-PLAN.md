use std::sync::Mutex;
use std::time::Duration;
use tracing::Span;
use crate::ga::TerminationCause;

3. Struct definition — store `Mutex<Option<Span>>` (NOT `EnteredSpan` which is `!Send`):
```rust
pub struct TracingObserver {
    run_span: Mutex<Option<Span>>,
    gen_span: Mutex<Option<Span>>,
}
```

4. `TracingObserver::new()` returning `Self` with both fields as `Mutex::new(None)`.

5. `impl Default for TracingObserver` delegating to `new()`.

6. `impl<U: ChromosomeT> GaObserver<U> for TracingObserver` with all 12 hooks:

   - `on_run_start`: Create `tracing::info_span!("ga_run")`, store in `run_span`. Emit `tracing::info!("ga run started")`.

   - `on_generation_start(generation)`: Lock `run_span`, enter it via `span.enter()` to establish parent context, create `tracing::debug_span!("ga_generation", generation)`, store in `gen_span`. No separate event emitted.

   - `on_selection_complete(generation, duration, population_size)`: Lock `gen_span`, enter it, compute `duration_ms = duration.as_secs_f64() * 1000.0`, emit `tracing::trace!(generation, duration_ms, population_size, "selection_complete")`.

   - `on_crossover_complete(generation, duration, offspring_count)`: Same pattern as selection but with `offspring_count` field and message `"crossover_complete"`.

   - `on_mutation_complete(generation, duration, population_size)`: Same pattern, message `"mutation_complete"`.

   - `on_fitness_evaluation_complete(generation, duration, population_size)`: Same pattern, message `"fitness_evaluation_complete"`.

   - `on_survivor_selection_complete(generation, duration, population_size)`: Same pattern, message `"survivor_selection_complete"`.

   - `on_new_best(generation, _best)`: Lock `gen_span`, enter it. Get fitness via `_best.fitness()`. Emit `tracing::info!(generation, fitness, "new_best")`.

   - `on_stagnation(generation, stagnation_count)`: Lock `gen_span`, enter it. Emit `tracing::warn!(generation, stagnation_count, "stagnation detected")`.

   - `on_extension_triggered(event)`: Lock `gen_span`, enter it. Emit `tracing::info!(generation = event.generation, diversity = event.diversity, extension_type = event.extension_type, threshold = event.threshold, "extension_triggered")`.

   - `on_generation_end(stats)`: Lock `gen_span`, enter it. Emit `tracing::debug!(generation = stats.generation, best_fitness = stats.best_fitness, avg_fitness = stats.avg_fitness, worst_fitness = stats.worst_fitness, fitness_std_dev = stats.fitness_std_dev, population_size = stats.population_size, diversity = stats.diversity, "generation_end")`. Then drop the guard and set `gen_span` to `None` (drops the span).

   - `on_run_end(cause, all_stats)`: Lock `run_span`, enter it. Compute `total_generations = all_stats.len()`. Emit `tracing::info!(cause = ?cause, total_generations, "ga run ended")`. Then drop the guard and set `run_span` to `None`.

CRITICAL CONSTRAINTS:
- ZERO `log::*` calls anywhere in this file (prevents LogTracer infinite recursion — TRAC-03)
- Store `Mutex<Option<Span>>` NOT `Mutex<Option<EnteredSpan>>` (`EnteredSpan: !Send` would break `GaObserver: Send + Sync`)
- Use `avg_fitness` (the actual struct field name), NOT `mean_fitness`
- The `on_generation_end` must emit the event BEFORE dropping the gen_span (set to None)
- The `on_generation_start` must enter `run_span` BEFORE creating `gen_span` so the subscriber registers the parent-child relationship
