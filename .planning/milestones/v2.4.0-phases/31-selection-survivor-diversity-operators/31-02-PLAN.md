   ```rust
   fn hamming_distance<U: ChromosomeT>(a: &U, b: &U) -> usize {
       let len = a.dna().len().min(b.dna().len());
       a.dna()[..len].iter()
           .zip(b.dna()[..len].iter())
           .filter(|(ga, gb)| ga.id() != gb.id())
           .count()
   }
   ```

4. **Implement core DC algorithm** in `deterministic_crowding`:
   - Emit `debug!(target="survivor_events", method="deterministic_crowding"; "Starting deterministic crowding survivor selection");` at entry.
   - Empty-input guard: `if chromosomes.is_empty() { return; }`.
   - Partition indices: `let parents: Vec<usize> = (0..chromosomes.len()).filter(|&i| chromosomes[i].age() > 0).collect();` and `let offspring: Vec<usize> = (0..chromosomes.len()).filter(|&i| chromosomes[i].age() == 0).collect();`.
   - `let mut used_parents: Vec<bool> = vec![false; parents.len()];`
   - `let mut survivors: Vec<usize> = Vec::with_capacity(chromosomes.len());`
   - For each `&off_idx in &offspring`:
     - Find the closest unused parent: iterate `parents.iter().enumerate().filter(|(pi, _)| !used_parents[*pi])` and pick the one minimizing `hamming_distance(&chromosomes[off_idx], &chromosomes[par_idx])`. Use `min_by_key`. On Hamming tie, the first-encountered wins (deterministic).
     - If `Some((pi, &par_idx))`: mark `used_parents[pi] = true;`. If `chromosomes[off_idx].fitness() >= chromosomes[par_idx].fitness()`, push `off_idx`; else push `par_idx`. Emit `trace!(target="survivor_events", method="deterministic_crowding"; "Offspring {} vs parent {}: survivor chosen", off_idx, par_idx);`.
     - If `None` (no available parent): push `off_idx` (D-06).
   - Append every unused parent: `for (pi, &par_idx) in parents.iter().enumerate() { if !used_parents[pi] { survivors.push(par_idx); } }`.

5. **Rebuild population in-place** (mirrors fitness.rs lines 50-65):
   ```rust
   survivors.sort_unstable();
   let mut new_pop: Vec<U> = survivors.iter().map(|&i| chromosomes[i].clone()).collect();
   if new_pop.len() > population_size {
       new_pop.sort_by(|a, b| b.fitness().partial_cmp(&a.fitness()).unwrap_or(std::cmp::Ordering::Equal));
       new_pop.truncate(population_size);
   }
   *chromosomes = new_pop;
   debug!(target="survivor_events", method="deterministic_crowding"; "Deterministic crowding survivor selection finished");
   ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-supplied chromosome DNA → `dna()` slice | Lengths can differ between parents and offspring (variable-length representations) |
| User-supplied fitness function → `chromosome.fitness()` | Fitness can be NaN/infinity |
| User-supplied gene IDs → `gene.id()` | Returns i32; no validity guarantee but type-safe |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-06 | Denial of Service (panic) | `hamming_distance` indexing | mitigate | Use `len = a.dna().len().min(b.dna().len())` slice (Task 1 step 3, D-08). Prevents out-of-bounds on length mismatch. |
| T-31-07 | Denial of Service (panic) | empty population dispatch | mitigate | Explicit `if chromosomes.is_empty() { return; }` at function entry (Task 1 step 4). |
| T-31-08 | Tampering (logical) | NaN fitness in keep-the-fitter `>=` | accept | NaN comparisons return false → parent wins ties involving NaN. Documented; consistent with existing survivor operators. No silent panic. |
| T-31-09 | Denial of Service (panic) | final fitness sort `partial_cmp` | mitigate | Use `partial_cmp(...).unwrap_or(Ordering::Equal)` (Task 1 step 5). Mirrors fitness.rs precedent. |
| T-31-10 | Elevation of Privilege | unsafe code | accept | No `unsafe` introduced. |
</threat_model>
