<objective>
Rewrite the two inline `levy_flight` tests — which currently test the private functions `mantegna_sigma_u` and `gamma_approx` via `use super::*;` — as public-API observable-behavior tests against `levy_flight_mutation`, place them in a new `tests/operations/test_mutation_levy_flight.rs`, wire that file into `tests/test_operations.rs`, then delete the inline block from the source.

Purpose: Removes 1 of the 10 inline test blocks (issue #266). Private functions cannot be accessed from integration tests, so per D-01/D-03 the invariants (Mantegna sigma finite/positive, Gamma numerically correct) are re-expressed as the observable guarantee that `levy_flight_mutation` produces finite, in-range gene values rather than NaN/Inf.
Output: New wired test file; `src/operations/mutation/levy_flight.rs` with inline block removed and private functions untouched.
</objective>
