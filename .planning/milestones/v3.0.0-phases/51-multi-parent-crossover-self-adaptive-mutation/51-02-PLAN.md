    UNDX algorithm body: compute `centroid: Vec<f64>` as the per-gene mean (sum then divide by `parents.len() as f64`). Compute `sigma_xi = 0.35 / (parents.len() as f64 - 1.0).max(1.0).sqrt()` and `sigma_eta = 0.35 / (parents.len() as f64).sqrt()`. Compute primary direction `dir: Vec<f64>` as `parents[0].dna()[i].value (to_f64) - centroid[i]` per gene; compute `dir_norm = dir.iter().map(|x| x*x).sum::<f64>().sqrt().max(1e-14)`. Use `let mut rng = crate::rng::make_rng();`. Draw ONE global `eta` via Box-Muller scaled by `sigma_eta`. For each gene index `i`, draw an independent `xi` via Box-Muller scaled by `sigma_xi`; compute `raw = centroid[i] + eta * (dir[i] / dir_norm) + xi`; clamp to `parents[0].dna()[i].ranges[0]` only when ranges is non-empty (follow the sbx.rs idiom exactly); convert via `T::from_f64`; clone the gene from `parents[0].dna()[i]` and replace `gene.value`. SPX algorithm body: compute `epsilon = ((parents.len() + 2) as f64).sqrt()` and `centroid` exactly as UNDX. Build `expanded: Vec<Vec<f64>>` as per-parent `centroid[i] + epsilon * (parent_value[i] - centroid[i])`. Sample `r_k` for k in `0..n_par - 1` as `rng.random_range(0.0..1.0).powf(1.0 / (n_par - 1 - k) as f64)`, then push `1.0` to make `r.len() == n_par`. Initialize `offspring_vals = expanded[n_par - 1].clone();` then for `k` in `(0..n_par-1).rev()`, for each gene `i`: `offspring_vals[i] = r[k] * expanded[k][i] + (1.0 - r[k]) * offspring_vals[i]`. Clamp each `offspring_vals[i]` to `parents[0].dna()[i].ranges[0]`. Build child identically to UNDX. Edge case: if `parents.len() == 1` the validator already errored; if exactly 3 parents, the iterative combination still works.

    Create `src/operations/crossover/pcx.rs` with same imports. Signature mirrors `undx`. Validation matches. PCX algorithm body: set `sigma_eta = 0.1_f64` and `sigma_zeta = 0.1_f64`. Compute per-gene `spread[i] = max_value_across_parents[i] - min_value_across_parents[i]` (use `fold(f64::NEG_INFINITY, f64::max)` and `fold(f64::INFINITY, f64::min)` idiom). For each gene `i`: read `p0 = T::to_f64(parents[0].dna()[i].value)`; compute `directional: f64` as the sum over `parents.iter().skip(1)` of `box_muller_noise(rng, sigma_eta) * (T::to_f64(p.dna()[i].value) - p0)`; compute orthogonal `zeta = box_muller_noise(rng, sigma_zeta) * spread[i]`; compute `raw = p0 + directional + zeta`; clamp to `parents[0].dna()[i].ranges[0]`. Build child identically.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-02-01 | Tampering | `factory_multi_parent` parent slice | mitigate | Length validation: `parents.len() < 3` returns `Err(GaError::CrossoverError("Multi-parent crossover requires at least 3 parents"))`. DNA-length validation inside each operator returns a descriptive CrossoverError when parents have mismatched lengths. |
| T-51-02-02 | Tampering | UNDX/SPX/PCX gene clamping | mitigate | Every offspring gene value is clamped to `parents[0].dna()[i].ranges[0]` before `T::from_f64` conversion (only when ranges is non-empty). Prevents out-of-bounds gene values from propagating into the population. |
