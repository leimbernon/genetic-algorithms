## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-01 | Tampering | `SelfAdaptive::adapt_strategy_params` default impl | mitigate | Early-return when `strategy_params().len() == 0` — prevents division by zero in callers and infinite loops. Clamp every sigma to `sigma_min` after the log-normal update — prevents NaN/Inf propagation and ensures every sigma stays strictly positive. |
| T-51-02 | Tampering | `Range::set_dna` lazy init | mitigate | The `is_empty() && !dna.is_empty()` guard ensures the sigma vector is initialized exactly once per chromosome and never overwrites a user-supplied vector via `set_strategy_params`. |
| T-51-03 | Tampering | `Crossover::Undx { num_parents }` value supplied by user | accept | `num_parents` is a `usize`; values `< 3` will be rejected at runtime by `factory_multi_parent` in Plan 02. Configuration-time validation is not required; the engine error is sufficient for a library API. |
| T-51-04 | Information disclosure | Serde of `strategy_params` (D-14) | accept | Sigma values are checkpoint state, not secrets. Users who serialize a population accept exposure of evolved sigmas; this is the documented behavior. |
| T-51-SC | Tampering | npm/pip/cargo installs | n/a | No new package installs in this phase (see RESEARCH.md `## Package Legitimacy Audit`); no slopcheck checkpoint required. |
