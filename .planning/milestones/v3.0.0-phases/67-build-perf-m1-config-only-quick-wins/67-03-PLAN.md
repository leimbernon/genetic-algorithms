<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .cargo/config.toml -> cargo -> system linker | New `linker = "clang"` + `-fuse-ld=mold` causes cargo to invoke a different system binary. mold is provided by the official Ubuntu apt repository. |
| CI runner -> apt -> mold package | `apt-get install -y mold` runs as sudo. mold is an officially packaged Ubuntu 22.04+ system package; integrity is enforced by apt's signed-archive verification. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-67-03-T | Tampering | .cargo/config.toml | mitigate | Acceptance criteria assert exact key/value strings AND that the existing WASM block is preserved verbatim |
| T-67-03-T2 | Tampering | mold supply chain | accept | mold is an Ubuntu apt-signed package; same trust model as `apt-get install gcc`. No new threat vector. |
| T-67-03-D | Denial of service | Linux CI builds | mitigate | If mold install fails (e.g., apt mirror outage), revert path is documented in docs/DEVELOPMENT.md §Reverting; CI can fall back to default ld trivially |
| T-67-03-SC | Tampering | npm/pip/cargo installs | accept | No crate dep added; dep_count invariant preserved |
