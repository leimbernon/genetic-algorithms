<objective>

have no benchmark coverage: PSO (`PsoEngine`) and CMA-ES (`CmaEngine`). Each
bench is parameterized on problem dimension (`dims_10` / `dims_30` / `dims_100`
per D-08) and runs both the sphere and Rastrigin problems (per D-07) for
cross-engine comparison with `benches/alps.rs` and `benches/rastrigin.rs`.

Purpose: Close the engine-coverage gap for PSO and CMA-ES so the project's
`benches/` tree exercises every continuous optimizer (GOAL; closes #267).
Output: `benches/pso.rs`, `benches/cma_es.rs`, and two new `[[bench]]` entries
in `Cargo.toml`.
</objective>
