Create src/operations/crossover/variable_length.rs with two public functions:

`pub fn variable_length_trim<U: LinearChromosome>(p1: &U, p2: &U) -> Result<Vec<U>, GaError>`:
- Compute `len = p1.dna().len().min(p2.dna().len())`.
- If len == 0, return `Err(GaError::CrossoverError("VariableLength(Trim): both parents must have at least 1 gene".to_string()))`.
- If len == 1, use crossover point = 0 (child1 = all p2[..1], child2 = all p1[..1]) OR point = 1 (child1 = p1[..1], child2 = p2[..1]) — sample uniformly from {0, 1} using `rng.random_range(0..=1usize)`.
- Otherwise sample `point` from `1..len` (exclusive both ends ensures both parts non-empty after excluding boundary points; use `rng.random_range(1..len)` — this keeps both offspring non-empty).
- Build child_dna_1 = `d1[..point] + d2[point..len]` and child_dna_2 = `d2[..point] + d1[point..len]` using `Vec::with_capacity(len)` + `extend_from_slice`.
- Create two `U::new()` chromosomes, set DNA via `set_dna(Cow::Owned(...))`.
- Log `debug!(target="crossover_events", method="variable_length_trim"; "Trim crossover: len={} point={}", len, point)`.
- Return `Ok(vec![child_1, child_2])`.

`pub fn variable_length_pad<U: LinearChromosome>(p1: &U, p2: &U, alleles: Option<&[U::Gene]>) -> Result<Vec<U>, GaError>` where `U::Gene: Clone`:
- Compute `len = p1.dna().len().max(p2.dna().len())`.
- If len == 0, return error.
- Pad the shorter parent's DNA to length `len`: if `alleles` is `Some` and non-empty, sample random allele from alleles for each pad position; else clone a random gene from the shorter parent's existing DNA (fallback).
- Sample crossover `point` from `1..len` (or `0..=1` if len==1).
- Build children from the padded DNA slices using the same extend_from_slice pattern as trim.
- Log `debug!(target="crossover_events", method="variable_length_pad"; "Pad crossover: len={} point={}", len, point)`.
- Return `Ok(vec![child_1, child_2])`.

Add imports at top of file: `use crate::error::GaError; use crate::traits::LinearChromosome; use log::debug; use rand::Rng; use std::borrow::Cow;`
