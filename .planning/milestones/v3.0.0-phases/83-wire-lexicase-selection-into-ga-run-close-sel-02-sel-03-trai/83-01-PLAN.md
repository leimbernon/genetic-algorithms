<objective>
Wire Lexicase / EpsilonLexicase selection into the GA run path by adding `run_lexicase()` and `run_lexicase_with_callback()` to the existing `VectorFitness`-constrained `impl<U> Ga<U>` block (the same block that already holds `select_parents_lexicase()` at ~line 2435 of `src/engines/ga/mod.rs`). Add a clear runtime error guard in the standard `run_with_callback()` so users who misconfigure Lexicase on the standard path get a message pointing them to `run_lexicase()`.

This closes the SEL-02 / SEL-03 / TRAITS-01 gap from Phase 50: the operator, the `VectorFitness` trait, and `selection::factory_lexicase()` are all complete, but `Ga::run()` never calls `factory_lexicase` — it unconditionally calls `selection::factory()`, which explicitly errors on the lexicase variants.

Purpose: Make `Selection::Lexicase` and `Selection::EpsilonLexicase` actually usable from a full GA run, without breaking any existing `Ga<U>` user (no new bound on the base impl block).
Output: New public methods `run_lexicase()` / `run_lexicase_with_callback()`; a clearer ConfigurationError in `run_with_callback()` for the lexicase variants.
</objective>
