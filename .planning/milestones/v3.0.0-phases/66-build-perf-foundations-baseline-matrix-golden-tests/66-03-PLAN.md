Name: `Build perf gate`

Single job named `build-perf-gate` using `runs-on: ubuntu-latest`.

`permissions: contents: read`

Steps:
1. `actions/checkout@v4`
2. `dtolnay/rust-toolchain@stable` with `targets: wasm32-unknown-unknown`
3. `Swatinem/rust-cache@v2` — include this for the non-gate build steps (only `cargo clean && cargo build` inside the script bypasses the cache; the wasm check and test steps benefit from cached deps).
   - CRITICAL (per D-04): Do NOT add `mozilla-actions/sccache-action` to this job. Do NOT set `RUSTC_WRAPPER=sccache`. The build-perf-gate measures cold build time; sccache would make the measurement meaningless.

The comparison step reads `target/build-perf/results.json` and `.planning/baselines/v3.0.0-baseline.json` using `python3`. Apply tolerance rules per D-09:
- Timing fields (`dev_build_s`, `wasm_check_s`, `test_suite_s`): fail if `(current - baseline) / baseline > 0.02` (2% tolerance). Improvement (negative delta) never fails.
- Exact fields (`dep_count`, `public_api_hash`): fail if current value != baseline value (0% tolerance).
- `captured_at`: skip comparison (date field, always changes).

The Python comparison script (written inline in the `run:` block):
- Load both JSON files with `json.load`.
- For each timing field: compute `delta = (cur - base) / base`. If `delta > 0.02`, print `"REGRESSION: {field} regressed {delta:.1%} (was {base}, now {cur})"` and `sys.exit(1)`.
- For `dep_count`: if `cur != base`, print `"REGRESSION: dep_count changed from {base} to {cur}"` and `sys.exit(1)`.
- For `public_api_hash`: if `cur != base` and `cur != "unavailable"` and `base != "unavailable"`: print `"REGRESSION: public_api_hash changed"` and `sys.exit(1)`. If either is `"unavailable"`, skip with a warning print.
- If all checks pass, print `"Build perf gate: all metrics within tolerance"` and exit 0.

Add a summary step that prints the JSON diff between baseline and current using `python3 -c "import json,sys; b=json.load(open('.planning/baselines/v3.0.0-baseline.json')); c=json.load(open('target/build-perf/results.json')); [print(f'{k}: {b.get(k)} → {c.get(k)}') for k in b]"` — always runs (no `if: always()` needed since it follows the comparison step which may fail).

Do NOT set `RUSTC_WRAPPER`, `SCCACHE_GHA_ENABLED`, or any sccache-related env vars in this job or workflow.

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-66-03-02 | Repudiation | build-perf-gate result | accept | CI log is immutable artifact in GitHub Actions; job output is preserved |
