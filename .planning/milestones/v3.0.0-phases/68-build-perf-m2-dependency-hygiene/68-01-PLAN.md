<objective>
Remove the env_logger auto-install anti-pattern from the library, delete the dead LogLevel / with_logs() / log_level plumbing it powered, move env_logger to [dev-dependencies], update examples to install their own logger, add an integration test that proves the library never installs one, and record the rationale for future agents.

Purpose: Sheds ~12 transitive crates and ~15-25% clean build wall-clock; restores idiomatic library hygiene (apps own logger installation, not libraries).

Output: Cargo.toml + 4 source files + 24 examples + 1 new integration test + 4 docs + 1 intel file, all committed atomically with `Revert plan:` lines.
</objective>
