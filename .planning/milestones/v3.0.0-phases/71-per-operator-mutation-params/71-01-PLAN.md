<objective>
Reshape the `Mutation` enum's 8 parameterized variants from inline-struct form to tuple form carrying named parameter structs (D-03, D-04), and update the dispatch layer in `mutation.rs` to destructure the new shape, remove the dead `factory_with_params` shim (D-05), and simplify `factory_with_chromosome_length` (D-06). This is a behavior-preserving refactor: every documented default value remains, only the type shape changes.

Purpose: Closes GitHub issue #249 — eliminate the one-size-fits-all `mutate(step, sigma)` plumbing by giving each operator its own typed parameter struct.
Output: 8 new public param structs in `src/operations.rs`; reshaped enum; updated dispatch and factory functions in `src/operations/mutation.rs`.
</objective>
