## v2.3.0 Requirements

### Directory Restructure (STRUCT)

- [x] **STRUCT-01**: `src/engines/` groups all engine modules (ga, island, nsga2, de, scatter, cellular, alps); lib.rs re-exports preserve all existing public paths — ✓ shipped Phase 25
- [x] **STRUCT-02**: `src/types/` groups chromosomes and genotypes modules; lib.rs re-exports preserve all existing public paths — ✓ shipped Phase 25
- [x] **STRUCT-03**: `src/observe/` groups observer, reporter, visualization, and checkpoint modules; lib.rs re-exports preserve all existing public paths — ✓ shipped Phase 25
- [x] **STRUCT-04**: All existing tests pass after restructure (`cargo test`, `cargo test --features serde`, `cargo clippy`, zero rustdoc warnings) — ✓ 657 tests passed, 0 warnings

### Differential Evolution (DE)

- [x] **DE-01**: User can run Differential Evolution with 5 mutation strategies: rand/1, best/1, current-to-best/1, rand/2, best/2 — ✓ shipped Phase 26
- [x] **DE-02**: User can configure binomial or exponential crossover for DE — ✓ shipped Phase 26
- [x] **DE-03**: User can run JADE adaptive variant with self-adaptive F and CR parameters — ✓ shipped Phase 26
- [x] **DE-04**: User can run L-SHADE adaptive variant with historical memory for F and CR — ✓ shipped Phase 26
- [x] **DE-05**: DE engine accepts any type implementing `ChromosomeT` + `GeneT` — ✓ shipped Phase 26 (via DeGene trait extension)
- [x] **DE-06**: Unit tests in `tests/` cover all 5 mutation strategies and both crossover modes — ✓ 11 tests in test_de.rs
- [x] **DE-07**: Criterion benchmark on continuous optimization — ✓ mutation strategy benchmark on sphere 5D; DE-vs-GA comparison deferred

### Scatter Search (SCAT)

- [x] **SCAT-01**: User can run Scatter Search with configurable diversification phase — ✓ shipped Phase 27
- [x] **SCAT-02**: User can configure reference set size; engine manages reference set updates — ✓ shipped Phase 27
- [x] **SCAT-03**: Engine combines reference set solutions to generate new candidates — ✓ shipped Phase 27
- [x] **SCAT-04**: User can optionally enable local search post-processing — ✓ shipped Phase 27
- [x] **SCAT-05**: Scatter Search engine accepts any `ChromosomeT` + `GeneT` type — ✓ shipped Phase 27
- [x] **SCAT-06**: Unit tests in `tests/` cover diversification, reference set management, and combination — ✓ 7 tests in test_scatter.rs
- [x] **SCAT-07**: Criterion benchmark on standard test functions — ✓ sphere 5D with/without local search

### Cellular GA (CELL)

- [x] **CELL-01**: User can run Cellular GA on 2D toroidal grid with configurable dimensions — ✓ shipped Phase 28
- [x] **CELL-02**: User can choose from 4 neighborhood types (VonNeumann, Moore, CompactR2, Linear) — ✓ shipped Phase 28
- [x] **CELL-03**: User can choose synchronous or asynchronous update mode — ✓ shipped Phase 28
- [x] **CELL-04**: Cellular GA accepts any `ChromosomeT` + `GeneT` and reuses existing operators — ✓ shipped Phase 28
- [x] **CELL-05**: Unit tests in `tests/` cover each neighborhood type and both update modes — ✓ 10 tests in test_cellular.rs
- [x] **CELL-06**: Criterion benchmark compares cellular throughput — ✓ all 4 neighborhoods + sync vs async on sphere

### ALPS (ALPS)

- [x] **ALPS-01**: User can run ALPS with age-layered population structure and configurable layers — ✓ shipped Phase 29
- [x] **ALPS-02**: User can choose from 3 age schemes: linear, Fibonacci, polynomial — ✓ shipped Phase 29
- [x] **ALPS-03**: Engine supports cross-layer mating between adjacent layers — ✓ shipped Phase 29 (20% cross-layer probability)
- [x] **ALPS-04**: Engine periodically injects fresh random individuals into youngest layer — ✓ shipped Phase 29
- [x] **ALPS-05**: ALPS engine accepts any `ChromosomeT` + `GeneT` and reuses existing operators — ✓ shipped Phase 29
- [x] **ALPS-06**: Unit tests in `tests/` cover age schemes, cross-layer mating, and injection — ✓ 11 tests in test_alps.rs
- [x] **ALPS-07**: Criterion benchmark compares ALPS convergence — ✓ ALPS vs DE + all 3 age schemes on sphere
