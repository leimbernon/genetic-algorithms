- Description: Extends NSGA-II for many-objective optimization (3+ objectives). Replaces crowding distance with reference-point association. Reference points are auto-generated via Das-Dennis simplex lattice (divisions per objective = p). Each solution associates with the closest reference line, and niche preservation selects solutions to cover all reference points evenly.

- Complete example: Nsga3Ga on DTLZ2 with 3 objectives
- Cross-reference: When to choose NSGA-III vs MOEA/D

Fitness is computed from raw strength (how many archive members dominate you) plus density (k-nearest-neighbor distance in objective space). - Description: S-Metric Selection Evolutionary Multi-Objective Algorithm. Steady-state (mu+1) evolutionary algorithm: each generation produces one offspring, adds it to the population, then removes the individual with the smallest hypervolume contribution (least contribution to the dominated hypervolume). Uses fast hypervolume computation (2D Lebesgue measure). The hypervolume indicator simultaneously captures convergence and diversity.
- When to Use: 2+ objectives (best at 2-3), continuous variables, problems where a single quality metric matters, when Pareto front shape benefits from hypervolume maximization
- Mandatory params: population_size, max_generations, dimensions, n_objectives, fitness_fn

- Complete example: SmsEmoaGa on ZDT1
- Cross-reference: When to choose SMS-EMOA vs IBEA vs NSGA-II
- References: Beume, Naujoks, & Emmerich (2007)

**For IBEA (src/engines/ibea/mod.rs):**
Replace current 10-line //! block with 50+ lines:

- Description: Indicator-Based Evolutionary Algorithm. Uses the additive epsilon indicator (I_eps+) to compute pairwise fitness values: fitness = sum of -e^(-I(b,a)/(c*kappa)) where c is the maximum absolute indicator value and kappa is a scaling factor. Environmental selection iteratively removes the individual with the smallest fitness contribution. Does not require a reference point.
- When to Use: 2+ objectives, continuous variables, when you want indicator-based selection without hypervolume computation cost, problems where reference point selection is difficult
- Mandatory params: population_size, max_generations, dimensions, n_objectives, fitness_fn
- Optional params: kappa (scaling factor, default 0.05), crossover, mutation
- Complete example: IbeaGa on ZDT1
- Cross-reference: When to choose IBEA vs SMS-EMOA
- References: Zitzler & Kunzli (2004)
