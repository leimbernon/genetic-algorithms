Update 5 operator guide files with new operators and verify accuracy.

**docs/operators/selection.md:**
- Add `Clearing` operator section:
  - Description: Promotes diversity by grouping individuals by niche radius. The best individual in each niche is preserved; all others within the niche are cleared (removed from the selection pool). Prevents a single region from dominating the population.
  - Configuration: niche_radius (f64) — individuals within this distance are considered in the same niche
  - When to use: Multimodal problems, niching, maintaining population diversity
  - Enum variant: `Selection::Clearing { niche_radius: f64 }`
  - Added in: v2.4.0

**docs/operators/crossover.md:**
- Add `EdgeRecombination` operator section:
  - Description: Preserves parental adjacency relationships by building an edge map (adjacency list) from both parents, then constructing offspring via edge recombination. Best for permutation problems (TSP, scheduling). Produces offspring that respect the adjacency relationships present in either parent.
  - Configuration: No additional parameters — operates on both parents' adjacency
  - When to use: Permutation problems, TSP, scheduling, any problem where adjacency matters
  - Enum variant: `Crossover::EdgeRecombination`
  - Added in: v2.4.0

**docs/operators/mutation.md:**
- Add 4 new operator sections:
  - `Cauchy`: Heavy-tailed perturbation using Cauchy (Lorentzian) distribution. scale parameter controls spread. Produces occasional large jumps beyond what Gaussian can achieve. Variant: `Mutation::Cauchy { scale: f64, probability: f64 }`. Added v2.4.0.
  - `LevyFlight`: Long-range jumps via Mantegna algorithm with Levy alpha-stable distribution. stability_index (α) controls tail heaviness. For very rugged landscapes. Variant: `Mutation::LevyFlight { stability_index: f64, probability: f64 }`. Added v2.4.0.
  - `Uniform`: Random gene reset to uniform value within gene's valid range. Equivalent to random re-initialization of selected genes. Variant: `Mutation::Uniform { probability: f64 }`. Added v2.4.0.
  - `Differential`: DE-style mutation using three random population members to generate a mutant vector with configurable F scale factor. Only applicable to real-valued genes. Variant: `Mutation::Differential { scale_factor: f64 }`. Added v2.4.0.
- Also add `NonUniform` if missing (check current content)

**docs/operators/survivor.md:**
- Add `DeterministicCrowding` operator section:
  - Description: Pairs each offspring with its most similar parent (by genotypic distance). The fitter of each pair survives. Ensures offspring replace genetically similar individuals, preserving population niches and diversity.
  - Configuration: No additional parameters
  - When to use: Multimodal problems, niching, steady-state replacement
  - Enum variant: `Survivor::DeterministicCrowding`
  - Added in: v2.4.0
