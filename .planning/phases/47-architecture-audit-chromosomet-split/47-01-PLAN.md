<objective>
Split the all-in-one `ChromosomeT` trait into a minimal evaluation contract (`ChromosomeT`) and a supertrait for flat-slice chromosomes (`LinearChromosome: ChromosomeT`). Write Wave 0 unit tests that lock in the new contracts BEFORE moving on to implementor updates and bound changes (47-02, 47-03).

Purpose: Implements ARCH-01 (minimal ChromosomeT) and the trait-definition half of ARCH-02 (LinearChromosome). Establishes the type-level foundation that the entire v3.0.0 milestone (Phases 48-53) builds on. Tree chromosomes (Phase 53) and variable-length chromosomes (Phase 52) need to implement ChromosomeT WITHOUT being forced to fake flat-slice methods.

Output: New `src/traits/linear_chromosome.rs`, shrunken `src/traits/chromosome.rs`, Wave 0 tests in `tests/traits/`, updated `src/traits/mod.rs` and `src/lib.rs` re-exports.
</objective>
