    **Part A: plot_diversity in src/visualization/mod.rs**

    Add `pub fn plot_diversity(stats: &[GenerationStats], path: &str) -> Result<(), VisualizationError>`:
    1. Return `Err(VisualizationError::InsufficientData)` if `stats.len() < 2`
    2. Use the same backend dispatch pattern as `plot_fitness` (match on path extension, BitMapBackend for ".png", SVGBackend for ".svg", else UnsupportedFormat)
    3. Chart dimensions: 800x600, fill WHITE
    4. Single `LineSeries` plotting `(s.generation, s.diversity)` for each stat entry, using BLUE color
    5. Caption: "Diversity over Generations"
    6. X-axis label: "Generation", Y-axis label: "Diversity"
    7. X range: `0usize..stats.last().unwrap().generation`
    8. Y range: compute min/max from diversity values; if `y_max - y_min < f64::EPSILON`, set `y_max = y_min + 1.0`
    9. No legend needed (single series) — but add `.label("Diversity")` and configure legend if desired (discretion)
    10. Call `root.present()` before returning
    11. All error conversions via `format!("{:?}", e)` pattern

    Either reuse the generic draw helper pattern from `plot_fitness` (factor out backend dispatch into a shared helper taking a closure), or duplicate the match arms. If duplicating, ensure the chart drawing logic is in a private `draw_diversity_chart` function to keep the public function clean.

    **Part B: plot_histogram in src/visualization/mod.rs**

    Add `pub fn plot_histogram(fitness_values: &[f64], path: &str) -> Result<(), VisualizationError>`:
    1. Return `Err(VisualizationError::InsufficientData)` if `fitness_values.is_empty()`
    2. Same backend dispatch pattern as above
    3. Chart dimensions: 800x600, fill WHITE
    4. Bin calculation:
       - `const NUM_BINS: u32 = 20;`
       - `let min = fitness_values.iter().cloned().fold(f64::INFINITY, f64::min);`
       - `let max = fitness_values.iter().cloned().fold(f64::NEG_INFINITY, f64::max);`
       - `let bin_width = if (max - min).abs() < f64::EPSILON { 1.0 } else { (max - min) / NUM_BINS as f64 };`
       - When `bin_width` comes from the degenerate case (all values equal), all values map to bin 0
    5. X-axis: `(0u32..NUM_BINS).into_segmented()` — CRITICAL: must use `.into_segmented()` for histogram (see Research Pitfall 3)
    6. Y-axis: `0u32..fitness_values.len() as u32` (upper bound — actual counts will be lower)
    7. Draw `Histogram::vertical(&chart).style(BLUE.mix(0.5).filled()).margin(1).data(fitness_values.iter().map(|&v| { let bin = ((v - min) / bin_width).min((NUM_BINS - 1) as f64) as u32; (bin, 1u32) }))`
    8. Caption: "Fitness Distribution"
    9. X-axis label: "Fitness Bin", Y-axis label: "Count"
    10. Call `root.present()` before returning
