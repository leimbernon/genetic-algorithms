## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-50-01 | Tampering | `MultiCaseFitness::set_case_fitness` accepts arbitrary `Vec<f64>` | accept | Validation belongs in Plan 02 `factory_lexicase` (NaN/empty guards). Trait is intentionally minimal per D-01. |
| T-50-02 | Information Disclosure | `case_fitness()` returns user-owned slice | accept | Read-only borrow; no cross-tenant leakage in a single-process library context. |
| T-50-03 | Denial of Service | User could populate huge `case_scores` vectors | accept | Bounded by user's own population size and case count; not a library-level concern. |

No network, auth, crypto, or secret-handling surface — Phase 50 is pure in-process algorithm + trait extension.
