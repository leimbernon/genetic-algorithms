  <behavior>
    - `lexicase_selection(&[U: ChromosomeT+MultiCaseFitness], number_of_couples)` returns `Vec<(usize, usize)>` of length `number_of_couples` (or `Vec::new()` if `chromosomes.len() < 2` or `case_fitness().is_empty()`).
    - Pair selection runs the single-winner filter cascade **twice independently per couple** — confirms research Open Question Q2: `(winner_run_a, winner_run_b)` per pair, never self-pairing under a non-degenerate population.
    - The case-index order shuffled before each single-winner filter run uses Fisher-Yates against `crate::rng::make_rng()` — so case order varies between successive calls with a randomized RNG.
    - The filter cascade for each winner: `pool = (0..n).collect()`. For each case in shuffled order, if `pool.len() <= 1` break; otherwise compute the per-case maximum across `pool`, retain indices whose `case_fitness[case] >= best` (lexicase) or `>= best - epsilon` (epsilon variant). If a final pool >1, choose uniformly at random.
    - `epsilon_lexicase_selection(&[U], number_of_couples, epsilon: Option<f64>)`: when `epsilon == None`, compute per-case MAD (Median Absolute Deviation from the per-case median) via `compute_mad_epsilons` exactly once before the pair loop, then pass per-case epsilons into the cascade. When `epsilon == Some(v)`, use the scalar `v` uniformly across all cases (D-11).
    - `compute_mad_epsilons(chromosomes, num_cases)` returns a `Vec<f64>` of length `num_cases` whose i-th entry is the median of `|s - median(scores_for_case_i)|` across the population — O(n log n) per case via `sort_unstable_by(partial_cmp)`.
    - `factory_lexicase(&mut [U], config, threads)` returns `Err(GaError::SelectionError)` if `chromosomes.len() < 2`, `case_fitness().is_empty()`, or any case score is `NaN`. Returns `Err(GaError::ConfigurationError)` if `config.method` is neither Lexicase nor EpsilonLexicase. On success, calls `lexicase_selection` or `epsilon_lexicase_selection`, then per D-04 iterates `chromosomes.iter_mut()` and calls `c.set_fitness(mean(case_scores))` on every individual whose `case_fitness()` is non-empty, then returns `Ok(pairs)`.
    - `selection::factory()` (existing) returns `Err(GaError::ConfigurationError)` with a message naming `factory_lexicase` when `config.method` is `Selection::Lexicase` or `Selection::EpsilonLexicase`.
    - `impl SelectionOperator for Selection` panics on the `Lexicase | EpsilonLexicase` arms with a message naming `factory_lexicase` (D-08).
    - No `par_iter()` / `into_par_iter()` / `rayon` import anywhere in `lexicase.rs` — sequential `.iter()` only. A comment near the inner loop explains the WASM constraint.
