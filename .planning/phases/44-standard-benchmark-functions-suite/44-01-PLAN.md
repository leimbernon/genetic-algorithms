    <step>3. Create `src/benchmarks/mod.rs`:
```rust
//! Standard benchmark functions for evaluating optimization algorithms.
//!
//! This module provides implementations of well-known single-objective,
//! bi-objective (ZDT), and many-objective (DTLZ) benchmark functions behind
//! the `benchmarks` feature flag.
//!
//! All functions implement the [`BenchmarkFn`] trait which provides a unified
//! `evaluate(&[f64]) -> Vec<f64>` interface along with metadata.

pub mod single_objective;

pub use single_objective::{Ackley, Rastrigin, Sphere};

/// Shared trait for all benchmark functions.
///
/// Provides a unified interface for evaluating benchmark functions and
/// accessing their metadata (name, bounds, known optimum).
pub trait BenchmarkFn {
    /// Human-readable name of the benchmark function.
    fn name(&self) -> &'static str;

    /// Per-dimension bounds as `(lower, upper)` pairs. Length equals the
    /// number of decision variables expected by `evaluate()`.
    fn bounds(&self) -> &[(f64, f64)];

    /// Known optimum objective vector. For single-objective this is
    /// `vec![f_min]`; for multi-objective it is `vec![f1_min, f2_min, ...]`.
    fn optimum_value(&self) -> Vec<f64>;

    /// Evaluate the benchmark function at point `x`.
    ///
    /// Returns a `Vec<f64>` containing one or more objective values.
    /// Single-objective functions return `vec![f]`; multi-objective functions
    /// return `vec![f1, f2, ..., fM]`.
    ///
    /// # Panics
    ///
    /// Panics if `x.len()` does not match the number of decision variables
    /// expected by the function (as returned by `bounds().len()`).
    fn evaluate(&self, x: &[f64]) -> Vec<f64>;
}
```
    Per D-04 (trait with 4 methods) and D-05 (single-objective returns vec![value]).</step>

    <step>4. Create `src/benchmarks/single_objective.rs` with three structs implementing `BenchmarkFn`:

    **Sphere:**
    - Struct: `pub struct Sphere { n: usize }`
    - `Sphere::new(n)` and `Default` (n=30 as a common default for benchmarks, matching ZDT conventions per Claude's discretion)
    - Formula: `f(x) = sum(x_i^2)` for i in 0..n
    - Domain: [-5.12, 5.12]^n
    - Optimum: f(0,...,0) = 0.0
    - `name()` returns `"Sphere"`
    - `bounds()` returns `&[(SPHERE_LOW, SPHERE_HIGH); self.n]` where const SPHERE_LOW = -5.12, SPHERE_HIGH = 5.12
    - `optimum_value()` returns `vec![0.0]`

    **Rastrigin:**
    - Struct: `pub struct Rastrigin { n: usize }`
    - `Rastrigin::new(n)` and `Default` (n=30)
    - Formula: `f(x) = 10*n + sum(x_i^2 - 10*cos(2*pi*x_i))` for i in 0..n
    - Domain: [-5.12, 5.12]^n
    - Optimum: f(0,...,0) = 0.0
    - Use `std::f64::consts::PI`
    - `name()` returns `"Rastrigin"`
    - `bounds()` returns `&[(RASTRIGIN_LOW, RASTRIGIN_HIGH); self.n]`
    - `optimum_value()` returns `vec![0.0]`

    **Ackley:**
    - Struct: `pub struct Ackley { n: usize }`
    - `Ackley::new(n)` and `Default` (n=30)
    - Formula: `f(x) = -20*exp(-0.2*sqrt((1/n)*sum(x_i^2))) - exp((1/n)*sum(cos(2*pi*x_i))) + 20 + e`
    - Domain: [-32, 32]^n
    - Optimum: f(0,...,0) = 0.0
    - Use `std::f64::consts::{E, PI}` — the formula has `+ e` at the end
    - `name()` returns `"Ackley"`
    - `bounds()` returns `&[(ACKLEY_LOW, ACKLEY_HIGH); self.n]`
    - `optimum_value()` returns `vec![0.0]`

    All three use `Default` impl that sets `n = 30` (consistent default matching literature conventions per Claude's discretion — D-07).

    Add `#[cfg(test)] mod tests` at the bottom of `single_objective.rs` with:

    - `test_sphere_nonzero`: Sphere::new(3).evaluate(&[1.0, 2.0, 3.0])[0] is within 1e-12 of 14.0 (1+4+9)
    - `test_rastrigin_optimum`: Rastrigin::default().evaluate(&vec![0.0; 30])[0] is within 1e-12 of 0.0
    - `test_rastrigin_nonzero`: Rastrigin::new(1).evaluate(&[1.0])[0] is within 1e-12 of 10 + 1 - 10*cos(2*pi) = 11 - 10*1 = 1.0 — wait: 10*1 + 1^2 - 10*cos(2*PI*1) = 10 + 1 - 10*1 = 1.0

    - `test_dimension_mismatch`: Ackley::new(3).evaluate(&[0.0, 0.0]) panics (wrong dimension)
    - `test_bounds_length_matches_dimension`: Sphere::new(5).bounds().len() == 5
