    derive(serde::Serialize, serde::Deserialize),

Key implementation details:
- `List::new(id: i32, alleles: Vec<T>, _value: T) -> Result<Self, GaError>` — validates `!alleles.is_empty()` and `0 <= id < alleles.len()`, then stores `value = alleles[id as usize].clone()` (ignores the `_value` argument per CONTEXT.md research note)
- `List::value(&self) -> T` — returns `self.value.clone()` (mirrors Range::value())
- `Default for List<T> where T: Default` — `List { id: 0, alleles: Vec::new(), value: T::default() }`
- `GeneT for List<T> where T: Clone + Sync + Send + Default` — `id()` returns `self.id`; `set_id(id)` checks `id >= 0 && (id as usize) < self.alleles.len()` before updating both `self.id` and `self.value = self.alleles[id as usize].clone()` — if out of bounds, log a warning and do nothing
- `Display for List<T> where T: Debug` — `write!(f, "{}:{:?}", self.id, self.value)` (mirrors Range's `id:value` format but uses `{:?}` since T has Debug not Display)
- Do NOT derive `PartialEq` on `List<T>` (T has no PartialEq bound). Instead, add a manual `impl<T: PartialEq> PartialEq for List<T>` so test assertions work when T: PartialEq
