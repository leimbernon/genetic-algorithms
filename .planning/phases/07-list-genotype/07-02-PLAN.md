```rust
//! List-value mutation operator for list-encoded chromosomes.
//!
//! Replaces a single gene's value with a different allele drawn from that
//! gene's own allele set. The "different" constraint is enforced by allele
//! index (gene.id), avoiding any `PartialEq` requirement on T.
```

Implement `pub fn list_value_mutation<T>(individual: &mut ListChromosome<T>)` where `T: Clone + Sync + Send + Default + Debug + 'static`:
1. `let len = individual.dna().len(); if len == 0 { return; }`
2. `let mut rng = crate::rng::make_rng();`
3. `let idx = rng.random_range(0..len);`
4. `let mut dna = individual.dna().to_vec();`
5. `let gene = &mut dna[idx];`
6. `if gene.alleles.len() < 2 { return; }` — guard against infinite loop
7. `let current_index = gene.id as usize;`
8. Pick new_index: `let new_index = loop { let n = rng.random_range(0..gene.alleles.len()); if n != current_index { break n; } };`
9. `gene.id = new_index as i32; gene.value = gene.alleles[new_index].clone();`
10. `individual.set_dna(Cow::Owned(dna));`

Then add `ValueMutable` impl for `ListChromosome<T>` — but this must go in `list_value.rs` (not in `chromosomes/list.rs`) to avoid circular imports. Follow the pattern from `value.rs` where `ValueMutable for RangeChromosome<i32>` is implemented:

```rust
use crate::chromosomes::ListChromosome;
use super::ValueMutable;

impl<T: Clone + Sync + Send + Default + Debug + 'static> ValueMutable for ListChromosome<T> {
    fn value_mutate(&mut self) {
        list_value_mutation(self);
    }
}
```

Note: The `ValueMutable` impl is generic over T, unlike the Range impls which are monomorphized per concrete type. This is fine because `ListChromosome<T>` does not need type-specific behavior (unlike Range where creep/gaussian need numeric operations).

**Function 1: `list_random_initialization`** (with repetition)

Signature matching the GA API pattern:
```rust
pub fn list_random_initialization<T>(
    genes_per_chromosome: usize,
    alleles: Option<&[List<T>]>,  // template genes carrying allele sets
    _needs_unique_ids: Option<bool>,
) -> Vec<List<T>>
where
    T: Clone + Sync + Send + Default + Debug,
```

Implementation:
1. `let alleles = alleles.expect("Alleles must be provided for list_random_initialization");`
2. `let mut rng = crate::rng::make_rng();`
3. `let mut dna = Vec::with_capacity(genes_per_chromosome);`
4. For each i in 0..genes_per_chromosome:
   a. Pick a template: `let template = &alleles[rng.random_range(0..alleles.len())];` (if multiple templates, random pick; if one template, always that one)
   b. Pick random allele index: `let index = rng.random_range(0..template.alleles.len());`
   c. Construct gene: `let gene = List::new(index as i32, template.alleles.clone(), template.alleles[0].clone()).expect("list_random_initialization: index always valid");`
   d. Push gene
5. Return dna
