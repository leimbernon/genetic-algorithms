<objective>
Generalize the selection API from 2-tuple parent pairs to N-ary parent groups (#248). `SelectionOperator::select` and `selection::factory` return `Vec<Vec<usize>>` instead of `Vec<(usize, usize)>`. The GA loop's `parent_crossover` consumes `&[Vec<usize>]` and dispatches crossover by `group.len()`, unifying the standard 2-parent path with the Phase-51 multi-parent (UNDX/SPX/PCX) path.

Purpose: Removes the separate multi-parent selection path; a single selection call now serves both standard and N-parent crossover. This is a v3.0.0 breaking change for custom `SelectionOperator` impls, documented in MIGRATION.md (Phase 65).

Output: Updated selection trait + factory, updated GA/island/GP/cellular call sites, an N=3 group-size test.
</objective>
