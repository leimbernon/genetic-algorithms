<objective>
Land the two clone-reduction targets per D-01 (relaxed) and D-03/D-04/D-05:

1. **Observer signature change (D-03/D-04/D-05):** Change `GaObserver<U>::on_new_best(&self, usize, U)` to `(&self, usize, &U)`. Propagate to all built-in impls (`LogObserver`, `CompositeObserver`, `TracingObserver`, `MetricsObserver`) and all test impls (`SpyObserver` in `test_observer.rs`; any observer impl in `tests/gp.rs` that overrides `on_new_best`). Update the call site in `ga.rs` (drop the `.clone()`) and the fan-out in `composite.rs` (remove the per-observer `.clone()`).

2. **Crossover fallback clone audit (D-01, relaxed by user):** Verify and document that the `parent_1.clone()` / `parent_2.clone()` at `src/engines/ga.rs` lines 2916-2917 are CONDITIONAL — they live inside the `else` branch of `if crossover_probability <= effective_crossover_prob` and only fire when crossover does not run. If any unconditional clone of `parent_1` or `parent_2` exists earlier in the `process_pair` closure (before the if/else), move it into the else branch. Per user decision, the "conditional clone" structure satisfies D-01 — no zero-copy take-ownership transfer is required.

Purpose: Contribute the hot-path clone reduction portion of the ≥10% wall-time reduction success criterion. Eliminates one per-generation chromosome clone in `on_new_best`, removes N-1 clones per new-best event in `CompositeObserver` fan-out, and guarantees the crossover fallback clones are not paid on the crossover-success path.

Output: Eight modified files (5 observer files + ga.rs + 2 test files); breaking change documented for v3.0.0.
</objective>
