Output: Modified engine files with observer support + integration tests proving all 5 hooks fire correctly.
</objective>

```rust
pub trait GaObserver<U: ChromosomeT>: Send + Sync {
    fn on_run_start(&self) {}
    fn on_generation_start(&self, _generation: usize) {}
    fn on_new_best(&self, _generation: usize, _best: U) {}
    fn on_generation_end(&self, _stats: &GenerationStats) {}
    fn on_run_end(&self, _cause: TerminationCause, _all_stats: &[GenerationStats]) {}
}
pub struct NoopObserver;
impl<U: ChromosomeT> GaObserver<U> for NoopObserver {}
```

```rust
pub enum TerminationCause {
    GenerationLimitReached, FitnessTargetReached, StagnationReached,

}

observer: Option<Arc<dyn GaObserver<U> + Send + Sync>>,

pub fn with_observer(mut self, observer: Arc<dyn GaObserver<U> + Send + Sync>) -> Self {
    self.observer = Some(observer); self
}

#[inline]
fn notify<F: FnOnce(&dyn GaObserver<U>)>(&self, f: F) {
    if let Some(ref obs) = self.observer { f(obs.as_ref()); }
}
```

| T-30-03 | I (Information Disclosure) | AlpsEngine on_generation_end merged stats | accept | Stats are aggregate fitness values (min/max/avg/stddev). No sensitive data. User already supplies the fitness function that produces these values. |
| T-30-04 | D (Denial of Service) | notify() dispatch in CellularEngine inner loop | mitigate | on_new_best is fired per-generation (after inner sweep), NOT per-cell.
