**Doc block** (`/*! ... */`):
- Title: "Island Model Parallel Evolution (Rastrigin 20D)"
- Problem description: Rastrigin function minimization with 20 dimensions -- harder than the single-population example (5D). Island model helps by maintaining diverse search strategies.
- GA mode: IslandGa with 4 islands, Ring topology, heterogeneous mutation rates
- Why heterogeneous: Each island uses a different mutation probability (0.01, 0.05, 0.10, 0.20) to balance exploration vs exploitation. Low mutation islands exploit promising regions; high mutation islands explore broadly.
- Key config: 4 islands, 50 per island, Ring topology, migration every 10 gens, 2 migrants per migration, 200 total generations
- Run command: `cargo run --example island_model`

**Rastrigin fitness function** (reuse from `examples/rastrigin.rs`):

```rust
let fitness_fn = |dna: &[RangeGenotype<f64>]| -> f64 {
    let a = 10.0;
    let n = dna.len() as f64;
    a * n + dna.iter().map(|g| g.value.powi(2) - a * (2.0 * std::f64::consts::PI * g.value).cos()).sum::<f64>()
};
```

**Island configuration:**
```rust
let island_config = IslandConfiguration::new()
    .with_num_islands(NUM_ISLANDS)
    .with_migration_interval(MIGRATION_INTERVAL)
    .with_migration_count(MIGRATION_COUNT)
    .with_topology(MigrationTopology::Ring);
```

**Heterogeneous GA configs:** Build 4 `GaConfiguration` instances with mutation probabilities [0.01, 0.05, 0.10, 0.20]. For each config, set fields directly:
```rust
let mutation_probs = [0.01_f64, 0.05, 0.10, 0.20];
let ga_configs: Vec<GaConfiguration> = mutation_probs.iter().map(|&prob| {
    let mut cfg = GaConfiguration::default();
    cfg.limit_configuration.population_size = POP_SIZE_PER_ISLAND;
    cfg.limit_configuration.genes_per_chromosome = DIMENSIONS;
    cfg.limit_configuration.problem_solving = ProblemSolving::Minimization;
    cfg.limit_configuration.max_generations = MAX_GENERATIONS;
    cfg.mutation_configuration.probability_max = Some(prob);
    cfg.mutation_configuration.method = Mutation::Gaussian;
    cfg.crossover_configuration.method = Crossover::Uniform;
    cfg.selection_configuration.method = Selection::Tournament;
    cfg.survivor = Survivor::Fitness;
    cfg
}).collect();
```

**Alleles:** `vec![RangeGenotype::new(0, vec![(-5.12_f64, 5.12_f64)], 0.0_f64)]`
