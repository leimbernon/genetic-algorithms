2. `AosState` struct — the runtime state machine for one operator portfolio:
   ```rust
   #[derive(Debug, Clone)]
   pub struct AosState {
       num_arms: usize,
       /// Per-arm sliding window ring buffers: arms[i].rewards[0..window_size)
       arms: Vec<ArmState>,
       /// Selection probabilities for PM/AP (uniform initial, sum=1.0).
       probabilities: Vec<f64>,
       /// Selection counts for MAB UCB.
       selection_counts: Vec<usize>,
       /// Total selections across all arms.
       total_selections: usize,
       /// The AOS strategy and parameters.
       strategy: AosStrategy,
       /// Reward window size.
       window_size: usize,
       /// Exploration phase length = window_size / 2.
       exploration_generations: usize,
   }
   ```

3. `ArmState` (private) — per-arm ring buffer:
   ```rust
   #[derive(Debug, Clone)]
   struct ArmState {
       rewards: Vec<f64>,
       cursor: usize,
       count: usize,
   }
   ```

**Constructors and methods on AosState:**

`AosState::new(num_arms: usize, strategy: AosStrategy, window_size: usize) -> Self`
- Creates `num_arms` ArmStates each with capacity `window_size`
- Initializes `probabilities` to `vec![1.0 / num_arms as f64; num_arms]`
- Initializes `selection_counts` to `vec![0; num_arms]`
- Sets `exploration_generations = window_size / 2`

`AosState::select_operator(&mut self, rng: &mut impl Rng, generation: usize) -> usize`
- If `generation < self.exploration_generations`: exploration phase — uniform random. Increment selection_counts and total_selections for the chosen arm. Return arm index.
- Post-exploration, dispatch by strategy:
  - PM/AP: roulette-wheel over `self.probabilities` (accumulate probability CDF, pick first where rng < cumulative/prob_sum).
  - MAB: with prob `epsilon`, uniform random; otherwise UCB1: compute `ucb_value = mean_reward(arm) + C * sqrt(2.0 * ln(total_selections as f64) / n_arm as f64)` for each arm where `n_arm > 0`. If any arm has `n_arm == 0`, select it (forced exploration). Otherwise select arm with max UCB value.
- Increment selection_counts and total_selections for chosen arm. Return arm index.

`AosState::record_rewards(&mut self, rewards: &[(usize, f64)])`
- For each `(op_idx, reward)` where `op_idx < num_arms`: call `self.arms[op_idx].add_reward(reward)`.

`AosState::update(&mut self)`
- Recompute probabilities for PM/AP:
  - Get `credit[j] = self.arms[j].mean_reward()` for each arm j
  - PM: for each j, `prob[j] = prob[j] + alpha * (credit[j] - prob[j])`. Clamp each to `[P_MIN, 1.0]` where `P_MIN = 1.0 / (num_arms as f64 * 1.5)`. Normalize to sum=1.0.
  - AP: find best arm j* with max credit. For j*: new_prob = prob[j*] + beta * (0.9 - prob[j*]). For all j != j*: new_prob = prob[j] + beta * (0.1 / (num_arms - 1) - prob[j]). Clamp to [0.01, 0.99], normalize sum to 1.0.
- MAB: no probability update needed (UCB handles exploration naturally).

**Private helper on ArmState:**
- `add_reward(&mut self, reward: f64)`: ring buffer write at cursor, advance cursor, increment count (capped at window_size).
- `mean_reward(&self) -> f64`: returns `rewards[..count.min(window_size)].iter().sum::<f64>() / count.max(1) as f64`.

**Free function:**

`compute_normalized_reward(parent_fitness: f64, offspring_fitness: f64, best_fitness: f64) -> f64`
- `let delta = parent_fitness - offspring_fitness`
- `let denom = best_fitness.abs().max(f64::EPSILON)` — clamp to avoid division by zero
- Return `delta / denom`
- Note: for minimization, positive delta = offspring better. For maximization, the GA loop negates if needed internally (the function does NOT take ProblemSolving — it always assumes lower fitness is better for the comparison. The GA loop passes (parent, offspring, best) with the correct sign depending on direction).
