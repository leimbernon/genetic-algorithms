    7. `pub fn run(&mut self) -> CmaResult<U>` — the main loop. Sequence:

       a. `let mut rng = make_rng();`
       b. `self.notify(|obs| obs.on_run_start());`
       c. Compute initial `pop_size`: if `self.config.population_size == 0`, defer (need n first). Initialize with a temporary sample: call `(self.init_fn)(1)` to peek at dimension OR require user to pass `population_size > 0` OR rely on `default_for_dim` having been called. Cleanest: call `(self.init_fn)(self.config.population_size.max(1))` first to read dimension `n = pop[0].dna().len()`; then if `self.config.population_size == 0`, compute `lambda = 4 + floor(3 * ln(n))` and re-initialize with `lambda` individuals. Use this approach.
       d. Evaluate fitness for the initial population. Initial `mean` = element-wise weighted average of the μ best (or simply the mean of all chromosomes' DNA coordinates — Hansen recommends mean of selected mu best, but the very first generation has no selection yet, so use the mean over all initial population coords as the seed mean).
       e. Initialize `state = CmaState::new(n, lambda, &self.config, initial_mean)`. Initial eigendecomposition: `let (b, d) = jacobi_eigendecompose(&state.c_mat, n); state.b_mat = b; state.d_vec = d; state.invsqrtc = compute_invsqrtc(&state.b_mat, &state.d_vec, n);`.
       f. Track `let mut best = pop.iter().enumerate().max_by(|a, b| ...).clone()` and `best_fitness`. Fire `on_new_best` once for the initial best.
       g. `let mut termination_cause = TerminationCause::GenerationLimitReached;`
       h. `let mut all_stats: Vec<GenerationStats> = Vec::with_capacity(self.config.max_generations);`
       i. `let template = pop[0].clone();` — used to reconstruct chromosomes from sampled f64 vectors.

       For `gen in 0..self.config.max_generations`:

       j. `self.notify(|obs| obs.on_generation_start(gen));`
       k. Sample λ offspring: for each `k in 0..lambda`, sample `z_k: Vec<f64>` (n independent N(0,1) via `standard_normal`), compute `y_k = matvec(b_mat, &dz, n)` where `dz[i] = d_vec[i] * z_k[i]`, compute `x_k[j] = mean[j] + sigma * y_k[j]`. Build offspring chromosome: clone `template`, then `set_dna(Cow::Owned(x_k.iter().enumerate().map(|(j, &v)| template.dna()[j].with_real_value(v)).collect()))`.
       l. Evaluate fitness for each offspring. Replace `pop` with the new offspring vector.
       m. Sort indices of `pop` by fitness in the favorable direction (ascending under Minimization, descending under Maximization). Extract μ best chromosomes.
       n. Compute `old_mean = state.mean.clone()`. Compute `new_mean[i] = sum_k weights[k] * x_{sorted[k]}[i]` where `x_sorted[k]` is the k-th best's DNA coordinates (extract via `chr.dna().iter().map(|g| g.real_value()).collect::<Vec<_>>()`).
       o. Compute step: `step[i] = (new_mean[i] - old_mean[i]) / sigma`.
       p. Update `ps`: `ps = (1-cs)*ps + sqrt(cs*(2-cs)*mu_eff) * invsqrtc * step`. Use `matvec` for the matrix-vector product.
       q. Compute `ps_norm = ps.iter().map(|x| x*x).sum::<f64>().sqrt()`.
       r. Compute `h_sigma = if ps_norm / (1.0 - (1.0 - cs).powi(2 * (gen + 1) as i32)).sqrt() / chi_n < 1.4 + 2.0 / (n as f64 + 1.0) { 1.0 } else { 0.0 }`.
       s. Update `pc`: `pc = (1-cc)*pc + h_sigma * sqrt(cc*(2-cc)*mu_eff) * step`.
       t. Update covariance `C`:
          - For each k in 0..mu, compute `y_k = (sorted_dna[k] - old_mean) / sigma` and accumulate the rank-mu update term `cmu * sum_k weights[k] * y_k * y_k^T` into a temporary `rank_mu_update` n×n.
          - Rank-one update: `c1 * (pc * pc^T + (1 - h_sigma) * cc * (2 - cc) * C)`.
          - Decay: `(1 - c1 - cmu) * C`.
          - Sum into `state.c_mat`.
          - Enforce symmetry: `c_mat[i*n + j] = (c_mat[i*n + j] + c_mat[j*n + i]) / 2` then mirror.
       u. Update sigma: `sigma *= ((cs / ds) * (ps_norm / chi_n - 1.0)).exp();` Clamp `sigma = sigma.max(1e-20).min(1e20)` to prevent NaN/Inf.
       v. Update mean: `state.mean = new_mean;`
       w. Eigendecomposition schedule: if `gen - state.eigeneval >= state.t_eigen`, recompute `(state.b_mat, state.d_vec) = jacobi_eigendecompose(&state.c_mat, n);` then `state.invsqrtc = compute_invsqrtc(&state.b_mat, &state.d_vec, n);` and set `state.eigeneval = gen`.
       x. Update best tracking via `find_best`. If improved, clone best and `self.notify(|obs| obs.on_new_best(gen, best_clone));`.
       y. Build `GenerationStats::from_fitness_values(gen, &fitness_values, is_maximization)`, push into `all_stats`, `self.notify(|obs| obs.on_generation_end(&stats));`.
       z. Early stop: if `let Some(target) = self.config.fitness_target { if self.reached_target(best_fitness, target) { termination_cause = TerminationCause::FitnessTargetReached; break; } }`.

       After the loop: `self.notify(|obs| obs.on_run_end(termination_cause, &all_stats));` and return `CmaResult { population: pop, best, best_fitness, generations: all_stats.len() }`.
