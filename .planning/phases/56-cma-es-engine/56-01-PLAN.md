<objective>
Rename the `DeGene` trait to `RealGene` and relocate it to `src/traits/real_gene.rs` as a shared trait used by `DeEngine`, `ScatterEngine`, and the upcoming `CmaEngine`. Cascade the rename across all 6 affected source files. Implement `RealGene` for both `Range<f64>` and `MultiRangeGenotype<f64>` so that both real-valued chromosome types work out-of-the-box with CMA-ES.

Purpose: This is a v3.0.0 breaking change (D-01) that unifies the gene-arithmetic trait under a name that is engine-neutral and reflects its true semantics. It also unblocks Plan 03 (CmaEngine) which bounds on `U::Gene: RealGene`.

Output: A new `src/traits/real_gene.rs` module, removed/re-exported `src/engines/de/gene.rs`, 4 DE/Scatter source files updated, `src/lib.rs` re-exporting `RealGene` alongside other trait re-exports, and a green `cargo test` + `cargo check --target wasm32-unknown-unknown`.
</objective>
