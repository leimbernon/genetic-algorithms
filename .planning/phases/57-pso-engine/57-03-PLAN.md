<interfaces>
PSO velocity update per particle `i`, per gene `d`, per generation `gen`:

  w = inertia_weight(&config.inertia, gen, config.max_generations)
  r1 = rng.random::<f64>()    // [0, 1)
  r2 = rng.random::<f64>()    // [0, 1)
  best_d = match config.topology {
    PsoTopology::Global                       => state.gbest_position[d],
    PsoTopology::Ring { neighborhood_size: k } => lbest_position_for(i, d, k, &state),
  }
  new_v = w * state.velocities[i][d]
        + config.c1 * r1 * (state.pbest_positions[i][d] - x_curr)
        + config.c2 * r2 * (best_d - x_curr)
  new_v = new_v.clamp(-state.v_max[d], state.v_max[d])
  new_x = x_curr + new_v
  match gene.bounds() {
    Some((lo, hi)) if new_x < lo => { new_x = lo; new_v = 0.0; }
    Some((lo, hi)) if new_x > hi => { new_x = hi; new_v = 0.0; }
    _ => {}
  }

Initial velocity per particle `i`, per gene `d` (D-02):
  range = bounds.map(|(lo, hi)| hi - lo).unwrap_or(1.0)
  v_init = rng.random::<f64>() * 2.0 * range - range    // uniform in [-range, +range]

v_max per gene (D-08): `v_max[d] = hi - lo` if `bounds()` is Some else `1.0`.

Ring neighborhood (D-04): for swarm of size `n`, with neighborhood_size `k`, particle `i`'s neighborhood is `{ (i + n - off) % n : off in 0..=(k/2) }  ∪  { (i + off) % n : off in 1..=((k+1)/2) }` clamped so `k = k.min(n - 1).max(1)`. The neighborhood includes particle `i` itself. lbest = the personal-best with the best fitness within that neighborhood (use `is_better` against pbest_fitness).
