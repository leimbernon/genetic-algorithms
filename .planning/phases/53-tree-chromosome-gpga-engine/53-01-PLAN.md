| Boundary | Description |
|----------|-------------|
| user → GpChromosome::dna() | Calling linear operator on a tree chromosome causes explicit panic (not silent data corruption) |
| user-supplied GpNode::evaluate() | User code executes inside fitness evaluation loop — panics propagate to engine level |
| user-supplied max_depth / max_node_count | Config values must be validated at build() time to prevent memory exhaustion |
