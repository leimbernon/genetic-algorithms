  <behavior>
    The example implements a "deceptive trap function" of the form: chromosome length 30 split into 6 blocks of size 5. Per-block score: if all 5 bits are 1 → reward = 5 (the global optimum per block); otherwise reward = (k - 1 - ones_count) where k=5, so all-zeros scores 4 and any partial-ones score < 4 — misdirecting hill-climbers toward all-zeros. Total fitness = sum of block scores. Global maximum is 30 (all bits 1, 6×5); deceptive local optimum is 24 (all bits 0, 6×4).

    The init_fn constructs `BinaryGenotype { id: if v { 1 } else { 0 }, value: v }` to satisfy the engine's Bernoulli indicator contract. This is the critical pedagogical point of the example (per CONTEXT.md Pitfall 1).

    - Configuration summary (pop_size, max_generations, selection_ratio)
    - Final result: generations run, best fitness, learned Bernoulli probability vector
    - Statement of whether the global optimum (fitness = 30.0) was reached
