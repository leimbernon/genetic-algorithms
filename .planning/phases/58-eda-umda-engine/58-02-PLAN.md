  <behavior>
    Per-generation UMDA loop (both variants share the structure; only estimation+sampling differ):
    1. Sort current population by fitness (Maximization: descending; Minimization: ascending). Use `sort_unstable_by` with NaN-safe `partial_cmp` and `Ordering::Equal` fallback.
    2. Compute `n_selected = max(1, floor(pop_size * selection_ratio))`. Slice top `n_selected` parents (references, no clone).
    3. Estimate model from selected parents:
       - Bernoulli: `p_i = (sum over selected of (gene_at_i.id() == 1 ? 1.0 : 0.0)) / n_selected`, then clamp to `[0.01, 0.99]` per position.
       - Gaussian: `mean_i = mean(gene_at_i.real_value())`, `std_i = sqrt(variance).max(1e-6)` per position.
    4. Sample `pop_size` new individuals by cloning a template (use `pop[0].clone()` as template), iterating positions, building new DNA:
       - Bernoulli: clone gene at position i, call `set_id(1)` or `set_id(0)` per `rng.random::<f64>() < p_i`.
       - Gaussian: Box-Muller `z = sqrt(-2 * ln(u1.max(1e-300))) * cos(2*PI*u2)`, `v = mean_i + std_i * z`, then `gene.bounds().map(|(lo,hi)| v.clamp(lo,hi)).unwrap_or(v)`, then `gene.with_real_value(v)`.
    5. Evaluate fitness for each offspring via `fitness_fn`. Parallelize with rayon on native, serial on wasm32.
    6. Replace `pop` with offspring.
    7. Compute fitness vector and GenerationStats; emit observer hooks; check fitness_target early stop.
    8. After loop: return EdaResult with `learned_model = last_model` (set inside the loop, never the initial all-0.5 placeholder).

    Observer hook ordering (must match PSO exactly):
    - `on_run_start()` once at the start, BEFORE initial population is built
    - After initial population is evaluated and best is identified: `on_new_best(0, best.clone())`
    - Per generation: `on_generation_start(gen)` → ... → `on_new_best(gen, best.clone())` (only if improved) → `on_generation_end(&stats)`
    - After loop: `on_run_end(termination_cause, &all_stats)`

    Empty population guard: panic with message `"EdaEngine: init_fn returned an empty population"` if `init_fn` returns 0 individuals.
    Population size default: `if config.population_size == 0 { 100 } else { config.population_size }`.
    No `Instant::now()` calls anywhere — follow PSO's no-timing approach.
  </behavior>
