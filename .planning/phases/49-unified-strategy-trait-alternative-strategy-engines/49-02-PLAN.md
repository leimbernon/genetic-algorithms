# Phase 49 - Plan 2: HillClimbEngine + HillClimbConfiguration

**Phase goal**: Users can swap between GA, hill-climbing, and exhaustive permutation search at runtime through a single `Strategy<U>` trait via `Box<dyn Strategy<U>>`.

**This plan delivers**: `HillClimbEngine<U>` (both `Stochastic` and `SteepestAscent` modes behind `HillClimbMode`), `HillClimbConfiguration`, observer wiring, and `impl Strategy<U> for HillClimbEngine<U>`. Module layout follows `src/engines/de/` exactly (D-11). After this plan, stochastic and steepest-ascent hill climbing are fully functional and can be boxed as `Box<dyn Strategy<U>>`.

**Depends on**: Plan 1 (requires `Strategy<U>` trait in `src/traits/strategy.rs`)

**Verification**: `cargo build` succeeds. `cargo test --test test_hill_climb` passes (tests scaffolded in Plan 4). `cargo check --target wasm32-unknown-unknown` passes.

### Task 1: Create `src/engines/hill_climb/configuration.rs`

**File**: `src/engines/hill_climb/configuration.rs`

**Action**: Create

**Details**:

Create `HillClimbMode` enum and `HillClimbConfiguration` struct following the `DeConfiguration` builder pattern from `src/engines/de/configuration.rs`.

**`HillClimbMode` enum** (per D-07):
- `Stochastic` — accept first neighbor with higher fitness; early exit from neighbor scan.
- `SteepestAscent` — evaluate all neighbors; accept only the global best.
- Derive `Debug, Clone, PartialEq`.

**`HillClimbConfiguration` struct** (per D-07/D-08, plus `FixedFitness` parity with `DeConfiguration`):

Fields:
- `pub mode: HillClimbMode` — default `HillClimbMode::Stochastic`
- `pub no_improvement_limit: usize` — default `100`. Stochastic mode stops when no improvement found for this many consecutive iterations. SteepestAscent uses `1` (stops on first non-improving step) but still reads this field — if mode is `SteepestAscent`, the engine treats convergence as stop condition regardless of the limit.
- `pub problem_solving: ProblemSolving` — default `ProblemSolving::Minimization`
- `pub fitness_target: Option<f64>` — default `None`. Early stop when `is_better(current_fitness, target)`.

Derive `Clone`. Import `use crate::configuration::ProblemSolving;`.

**Builder methods** (fluent, consume self):
- `pub fn with_mode(mut self, mode: HillClimbMode) -> Self`
- `pub fn with_no_improvement_limit(mut self, limit: usize) -> Self`
- `pub fn with_problem_solving(mut self, ps: ProblemSolving) -> Self`
- `pub fn with_fitness_target(mut self, t: f64) -> Self` — sets `fitness_target: Some(t)`

Implement `Default` returning the defaults listed above.

### Task 2: Create `src/engines/hill_climb/engine.rs`

**File**: `src/engines/hill_climb/engine.rs`

**Action**: Create

**Details**:

Implements `HillClimbEngine<U>` with observer wiring copied verbatim from `ga.rs` (lines 859-870). WASM constraint: use `.iter()` / `.into_iter()` only — never `.par_iter()`. No `Instant::now()` anywhere in this file.

**Struct definition**:

```rust
pub struct HillClimbEngine<U: LinearChromosome> {
    config: HillClimbConfiguration,
    neighbor_fn: Arc<dyn Fn(&U) -> Vec<U> + Send + Sync>,
    current: Option<U>,
    observer: Option<Arc<dyn GaObserver<U> + Send + Sync>>,
}
```

**`impl<U: LinearChromosome + Clone> HillClimbEngine<U>`**:

`pub fn new(config: HillClimbConfiguration, initial: U, neighbor_fn: impl Fn(&U) -> Vec<U> + Send + Sync + 'static) -> Self`:
- Sets `config`, `current: Some(initial)`, `neighbor_fn: Arc::new(neighbor_fn)`, `observer: None`.
- Initial solution is required at construction time (not optional — per open question resolution: mirrors `DeEngine::new()` pattern).

`pub fn with_observer(mut self, observer: Arc<dyn GaObserver<U> + Send + Sync>) -> Self`:
- Sets `self.observer = Some(observer); self`. Exact copy of the `ga.rs` pattern (D-02).

`#[inline] fn notify<F: FnOnce(&dyn GaObserver<U>)>(&self, f: F)`:
- Body: `if let Some(ref obs) = self.observer { f(obs.as_ref()); }`. Verbatim copy from `ga.rs` line 866-870 (D-04).

`fn is_better(&self, candidate: f64, current: f64) -> bool`:
- Copy the `DeEngine::is_better()` pattern from `src/engines/de/engine.rs` lines 237-249 exactly, but using `self.config.problem_solving` and `self.config.fitness_target`.

`pub fn run(&mut self) -> Result<(), GaError>`:

Algorithm (per D-04, D-07):

1. Take `current` via `self.current.take().ok_or(GaError::ConfigurationError("HillClimbEngine: no initial solution provided".to_string()))?`
2. `self.notify(|obs| obs.on_run_start());`
3. Init: `let mut no_improvement_count = 0usize; let mut iteration = 0usize; let mut all_stats: Vec<GenerationStats> = Vec::with_capacity(self.config.no_improvement_limit);`
4. Loop:
   - `self.notify(|obs| obs.on_generation_start(iteration));`
   - `let neighbors = (self.neighbor_fn)(&current);`
   - Branch on `self.config.mode`:
     - `HillClimbMode::Stochastic`: `neighbors.into_iter().find(|n| self.is_better(n.fitness(), current.fitness()))`
     - `HillClimbMode::SteepestAscent`: `neighbors.into_iter().filter(|n| self.is_better(n.fitness(), current.fitness())).max_by(|a, b| { if self.is_better(a.fitness(), b.fitness()) { std::cmp::Ordering::Greater } else { std::cmp::Ordering::Less } })`
   - If `Some(next)`: clone `next` for observer, call `self.notify(|obs| obs.on_new_best(iteration, next.clone()));`, set `current = next; no_improvement_count = 0;`
   - Else: `no_improvement_count += 1;`
   - Build `GenerationStats { generation: iteration, best_fitness: current.fitness(), worst_fitness: current.fitness(), avg_fitness: current.fitness(), fitness_std_dev: 0.0, population_size: 1, diversity: 0.0, dynamic_mutation_probability: None }`. Call `self.notify(|obs| obs.on_generation_end(&stats));`. Push `stats` to `all_stats`.
   - `iteration += 1;`
   - Early stop on fitness target: if `let Some(target) = self.config.fitness_target` and `self.is_better(current.fitness(), target)` → break.
   - Stopping condition (per D-07):
     - `Stochastic`: break when `no_improvement_count >= self.config.no_improvement_limit`
     - `SteepestAscent`: break when `no_improvement_count >= 1` (first non-improving step)
     - Unified: `let limit = match self.config.mode { HillClimbMode::Stochastic => self.config.no_improvement_limit, HillClimbMode::SteepestAscent => 1 }; if no_improvement_count >= limit { break; }`
5. `self.current = Some(current);`
6. `self.notify(|obs| obs.on_run_end(TerminationCause::GenerationLimitReached, &all_stats));`
7. `Ok(())`

`pub fn best(&self) -> Option<&U>`: Return `self.current.as_ref()` (after `run()`, `current` holds the best solution found).

**`impl<U: LinearChromosome + Clone> Strategy<U> for HillClimbEngine<U>`**:

- `fn run(&mut self) -> Result<(), GaError>` — delegate to `self.run()`
- `fn best(&self) -> Option<&U>` — delegate to `self.best()`

**Required imports** at top of file:
- `use std::sync::Arc;`
- `use crate::error::GaError;`
- `use crate::ga::TerminationCause;`
- `use crate::observer::GaObserver;`
- `use crate::stats::GenerationStats;`
- `use crate::traits::{LinearChromosome, Strategy};`
- `use super::configuration::{HillClimbConfiguration, HillClimbMode};`

Note on GA-only hooks: `on_selection_complete`, `on_crossover_complete`, `on_mutation_complete`, `on_survivor_selection_complete`, `on_fitness_evaluation_complete`, `on_extension_triggered`, `on_stagnation` MUST NOT fire in this engine (D-04). Only the five listed hooks fire.
