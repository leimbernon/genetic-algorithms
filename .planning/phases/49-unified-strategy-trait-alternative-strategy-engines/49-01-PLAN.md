# Phase 49 - Plan 1: Strategy Trait + Ga<U> Impl + Re-exports

## Tasks

### Task 1: Define `Strategy<U>` trait in `src/traits/strategy.rs`

**File**: `src/traits/strategy.rs`

**Action**: Create

**Details**:

Create the file with exactly the following content. The trait must be dyn-safe (D-01, D-03): no associated types, no generics on methods, both methods take `Self` by reference only.

```
// Per D-01/D-03: minimal two-method dyn-safe trait
pub trait Strategy<U: ChromosomeT> {
    fn run(&mut self) -> Result<(), GaError>;
    fn best(&self) -> Option<&U>;
}
```

- Import: `use crate::error::GaError;` and `use crate::traits::ChromosomeT;`
- Add crate-level doc comment: "Common interface over all search strategy engines. Enables runtime algorithm swapping via `Box<dyn Strategy<U>>`."
- The `run` method doc: "Execute the search loop. Mutates internal state."
- The `best` method doc: "Returns the best candidate found, or `None` if `run()` has not been called."
- No builder methods (D-01). No `with_observer` on the trait (D-02).
- Dyn-safety: `U` is the trait's type parameter bound at the `dyn Strategy<U>` site — not a method-level generic. Both methods are dyn-safe. No `Self` in non-receiver position.

### Task 2: Implement `Strategy<U>` for `Ga<U>` in `src/engines/ga.rs`

**File**: `src/engines/ga.rs`

**Action**: Add (new impl block at end of file)

**Details**:

Add the following impl block. Do NOT change any existing code in `ga.rs` — this is a purely additive impl block (D-12).

The impl block must use the full bound set that `run_with_callback` requires (line 1290): `U: LinearChromosome + Send + Sync + 'static + Clone + MaybeDeserialize`.

- `fn run(&mut self) -> Result<(), GaError>`: call `self.run().map(|_| ())`. The existing `Ga::run()` returns `Result<&Population<U>, GaError>` — discard the reference via `.map(|_| ())`.
- `fn best(&self) -> Option<&U>`: read `self.population.best_chromosome_is_set` (which is `pub(crate)` — accessible here) and return `Some(&self.population.best_chromosome)` if set, else `None`.

Required import at the top of the new impl block: `use crate::traits::Strategy;` (or add to the existing use block if `Strategy` is re-exported from `crate::traits`).

The impl must be placed AFTER all existing impls in `ga.rs`, as a new block:

```
impl<U> Strategy<U> for Ga<U>
where
    U: LinearChromosome + Send + Sync + 'static + Clone + MaybeDeserialize,
{
    fn run(&mut self) -> Result<(), GaError> {
        self.run().map(|_| ())
    }

    fn best(&self) -> Option<&U> {
        if self.population.best_chromosome_is_set {
            Some(&self.population.best_chromosome)
        } else {
            None
        }
    }
}
```
