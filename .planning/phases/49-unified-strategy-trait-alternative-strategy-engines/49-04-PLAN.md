### Task 2: Create `tests/engines/hill_climb/test_hill_climb.rs` (STR-02, STR-03)

**File**: `tests/engines/hill_climb/test_hill_climb.rs`

**Action**: Create

**Details**:

Tests for `HillClimbEngine` covering stochastic and steepest-ascent modes, stopping conditions, and observer hook ordering.

Use `RangeChromosome<f64>` with a simple 1D landscape: fitness = `gene.value.abs()` (minimization — solution at 0.0). Neighbor function moves gene value by ±0.1 steps: returns two neighbors.

**Test: `test_stochastic_finds_improvement`** — Verifies STR-02 success criterion 2.

Build `HillClimbEngine` with `HillClimbMode::Stochastic`, `no_improvement_limit: 10`, initial chromosome at `value=5.0`. Neighbor function returns chromosome at `value - 0.1` and `value + 0.1`. Run to completion. Assert `best()` returns chromosome with lower fitness than initial (fitness < 25.0).

**Test: `test_stochastic_stops_on_no_improvement_limit`** — Verifies STR-02 stopping behavior.

Build engine with `no_improvement_limit: 3`. Neighbor function always returns chromosomes with WORSE fitness than current (fitness higher than current). Run. Assert the engine terminates (does not loop forever) and `best()` is the initial chromosome.

**Test: `test_stochastic_observer_hooks_order`** — Verifies STR-02 observer wiring (D-04).

Attach a tracking observer (struct with `Mutex<Vec<String>>` that records hook names). Run 1 iteration that finds an improvement. Assert the hook sequence includes in order: `"run_start"`, `"gen_start"`, `"new_best"`, `"gen_end"`, and eventually `"run_end"`. Assert `"selection_complete"`, `"crossover_complete"`, `"mutation_complete"` are NOT in the recorded hooks.

**Test: `test_steepest_ascent_converges`** — Verifies STR-03 success criterion 3.

Build engine with `HillClimbMode::SteepestAscent`. Same 1D landscape. Neighbor function returns 5 neighbors at ±0.1, ±0.2, ±0.5 offsets. Assert `best()` has lower fitness than initial after run (SteepestAscent picks globally best neighbor per step).

**Test: `test_steepest_ascent_stops_on_no_improvement`** — Verifies STR-03 stopping.

Neighbor function returns only neighbors with worse fitness. Assert engine stops after 1 non-improving step (SteepestAscent `no_improvement_count >= 1`).

**Test: `test_steepest_ascent_empty_neighbor_list`** — Verifies Pitfall 3 safety.

Neighbor function returns `vec![]` (empty). Assert engine does not panic, terminates, and `best()` returns the initial chromosome.

**Observer tracking struct** (shared helper in this test file):

```rust
use std::sync::{Arc, Mutex};
use genetic_algorithms::GaObserver;
use genetic_algorithms::ga::TerminationCause;
use genetic_algorithms::stats::GenerationStats;

struct RecordingObserver {
    events: Mutex<Vec<String>>,
}

impl RecordingObserver {
    fn new() -> Arc<Self> { Arc::new(Self { events: Mutex::new(Vec::new()) }) }
    fn events(&self) -> Vec<String> { self.events.lock().unwrap().clone() }
}

impl<U: genetic_algorithms::traits::ChromosomeT> GaObserver<U> for RecordingObserver {
    fn on_run_start(&self) { self.events.lock().unwrap().push("run_start".to_string()); }
    fn on_generation_start(&self, _g: usize) { self.events.lock().unwrap().push("gen_start".to_string()); }
    fn on_new_best(&self, _g: usize, _best: U) { self.events.lock().unwrap().push("new_best".to_string()); }
    fn on_generation_end(&self, _stats: &GenerationStats) { self.events.lock().unwrap().push("gen_end".to_string()); }
    fn on_run_end(&self, _cause: TerminationCause, _all_stats: &[GenerationStats]) { self.events.lock().unwrap().push("run_end".to_string()); }
}
```

### Task 3: Create `tests/engines/permutate/test_permutate.rs` (STR-04)

**File**: `tests/engines/permutate/test_permutate.rs`

**Action**: Create

**Details**:

Tests for `PermutateEngine` covering basic evaluation, safety gate, and observer hooks.

Use `RangeChromosome<f64>` with pre-evaluated candidates (fitness set manually via `set_fitness()`).

**Test: `test_permutate_finds_best_candidate`** — Verifies STR-04 basic behavior.

Create 5 candidates with fitness values `[3.0, 1.0, 4.0, 1.5, 2.0]` under minimization. Build `PermutateEngine` with `safety_gate: 1000`. Run. Assert `best()` returns the candidate with `fitness() == 1.0`.

**Test: `test_permutate_maximization`** — Verifies `ProblemSolving::Maximization` path.

Create 3 candidates with fitness `[1.0, 5.0, 2.0]` under maximization. Assert `best()` returns the candidate with `fitness() == 5.0`.

**Test: `test_permutate_safety_gate_triggers`** — Verifies STR-04 gate behavior (D-06/D-10).

Create 10 candidates. Set `safety_gate: 3`. Run. Assert `run()` returns `Ok(())` (no error). Assert `best()` is `Some(_)` — best among the first 3 candidates. The `log::warn` fires internally; the test only verifies behavior, not log output (log testing is not required by the requirement).

**Test: `test_permutate_observer_hooks_per_candidate`** — Verifies STR-04 observer wiring (D-05).

Use `RecordingObserver` (same pattern as hill-climb tests, defined locally or in a shared helper). Create 3 candidates. Assert that after run:
- `"run_start"` appears exactly once
- `"gen_start"` appears exactly 3 times
- `"run_end"` appears exactly once
- `"new_best"` appears at least once
- `"selection_complete"` does NOT appear

**Test: `test_permutate_best_before_run_returns_none`** — Verifies Pitfall 2 safety.

Create engine. Call `best()` WITHOUT calling `run()`. Assert `best()` returns `None`.

**Test: `test_permutate_fitness_target_early_stop`** — Verifies early stop on fitness target.

Create 10 candidates with fitness `[5.0, 4.0, 3.0, 2.0, 1.0, 0.5, 0.1, 0.0, ...]`. Set `fitness_target: Some(1.5)` under minimization. Assert `run()` returns `Ok(())` and `best()` fitness is <= 1.5. The engine must stop early (before evaluating all 10 candidates) when the target is met.
