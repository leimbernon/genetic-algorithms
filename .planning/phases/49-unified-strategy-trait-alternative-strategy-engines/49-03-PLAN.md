# Phase 49 - Plan 3: PermutateEngine + PermutateConfiguration

**Phase goal**: Users can swap between GA, hill-climbing, and exhaustive permutation search at runtime through a single `Strategy<U>` trait via `Box<dyn Strategy<U>>`.

**This plan delivers**: `PermutateEngine<U>` (exhaustive candidate evaluation up to safety gate), `PermutateConfiguration`, observer wiring, and `impl Strategy<U> for PermutateEngine<U>`. Module layout follows `src/engines/de/` exactly (D-11). After this plan, all three engines implement `Strategy<U>` and the phase is feature-complete pending tests.

**Depends on**: Plan 1 (requires `Strategy<U>` trait). Plan 2 can be developed in parallel — no dependency between Plan 2 and Plan 3.

**Verification**: `cargo build` succeeds. `cargo test --test test_permutate` passes (tests scaffolded in Plan 4). `cargo check --target wasm32-unknown-unknown` passes.

### Task 2: Create `src/engines/permutate/engine.rs`

**File**: `src/engines/permutate/engine.rs`

**Action**: Create

**Details**:

Implements `PermutateEngine<U>` with observer wiring copied verbatim from `ga.rs` (lines 859-870). WASM constraint: use `.iter()` only — never `.par_iter()`. No `Instant::now()` in this file.

**Candidates fitness contract**: Candidates in `Vec<U>` must have fitness pre-evaluated by the caller before being passed to `PermutateEngine::new()` (D-09, and per the doc comment on `PermutateConfiguration`). The engine calls `candidate.fitness()` directly — if fitness is `NaN` (default uninitialized state), comparisons will behave as "not better" in IEEE 754 and `best()` may remain `None`. This is documented behavior, not an engine bug.

**Struct definition**:

```rust
pub struct PermutateEngine<U: ChromosomeT> {
    config: PermutateConfiguration,
    candidates: Vec<U>,
    best: Option<U>,
    observer: Option<Arc<dyn GaObserver<U> + Send + Sync>>,
}
```

Note: `PermutateEngine` is bounded on `ChromosomeT` (not `LinearChromosome`) because it only calls `fitness()` and does not access DNA (D-09 — candidates are pre-materialized by caller). This is a deliberate design choice.

**`impl<U: ChromosomeT + Clone> PermutateEngine<U>`**:

`pub fn new(config: PermutateConfiguration, candidates: Vec<U>) -> Self`:
- Sets fields: `config`, `candidates`, `best: None`, `observer: None`.

`pub fn with_observer(mut self, observer: Arc<dyn GaObserver<U> + Send + Sync>) -> Self`:
- Sets `self.observer = Some(observer); self`. Verbatim copy of `ga.rs` pattern (D-02).

`#[inline] fn notify<F: FnOnce(&dyn GaObserver<U>)>(&self, f: F)`:
- Body: `if let Some(ref obs) = self.observer { f(obs.as_ref()); }`. Verbatim copy from `ga.rs` line 866-870 (D-04).

`fn is_better(&self, candidate: f64, current: f64) -> bool`:
- Copy the `DeEngine::is_better()` pattern from `src/engines/de/engine.rs` lines 237-249, using `self.config.problem_solving` and `self.config.fitness_target`.

`pub fn run(&mut self) -> Result<(), GaError>`:

Algorithm (per D-05, D-06, D-09, D-10):

1. `self.notify(|obs| obs.on_run_start());`
2. Init: `let gate = self.config.safety_gate; let mut best: Option<U> = None; let mut all_stats: Vec<GenerationStats> = Vec::with_capacity(self.candidates.len().min(gate));`
3. For loop: `for (idx, candidate) in self.candidates.iter().enumerate()`:
   - If `idx >= gate`: emit `log::warn!(target = "ga_events", "PermutateEngine: safety gate of {} reached, stopping after {} candidates", gate, idx);` then `break;` (D-06 — no observer hook for gate overflow, only `log::warn`).
   - `self.notify(|obs| obs.on_generation_start(idx));` (D-05: each candidate is one "generation")
   - Compare: `let is_new_best = match &best { None => true, Some(b) => self.is_better(candidate.fitness(), b.fitness()) };`
   - If `is_new_best`: `self.notify(|obs| obs.on_new_best(idx, candidate.clone())); best = Some(candidate.clone());`
   - Build stats: `let best_fit = best.as_ref().map(|b| b.fitness()).unwrap_or(f64::NAN); let stats = GenerationStats { generation: idx, best_fitness: best_fit, worst_fitness: candidate.fitness(), avg_fitness: candidate.fitness(), fitness_std_dev: 0.0, population_size: 1, diversity: 0.0, dynamic_mutation_probability: None };` Call `self.notify(|obs| obs.on_generation_end(&stats));`. Push `stats` to `all_stats`.
   - Early stop on fitness target: if `let Some(target) = self.config.fitness_target` and `is_new_best && self.is_better(candidate.fitness(), target)` → break after the notify/push steps.
4. `self.best = best;`
5. `self.notify(|obs| obs.on_run_end(TerminationCause::GenerationLimitReached, &all_stats));` (D-06: reuse `GenerationLimitReached` — do not add new `TerminationCause` variants)
6. `Ok(())`

`pub fn best(&self) -> Option<&U>`: Return `self.best.as_ref()`.

**`impl<U: ChromosomeT + Clone> Strategy<U> for PermutateEngine<U>`**:

- `fn run(&mut self) -> Result<(), GaError>` — delegate to `self.run()`
- `fn best(&self) -> Option<&U>` — delegate to `self.best()`

**Required imports** at top of file:
- `use std::sync::Arc;`
- `use crate::error::GaError;`
- `use crate::ga::TerminationCause;`
- `use crate::observer::GaObserver;`
- `use crate::stats::GenerationStats;`
- `use crate::traits::{ChromosomeT, Strategy};`
- `use super::configuration::PermutateConfiguration;`

Note on GA-only hooks: `on_selection_complete`, `on_crossover_complete`, `on_mutation_complete`, `on_survivor_selection_complete`, `on_fitness_evaluation_complete`, `on_extension_triggered`, `on_stagnation` MUST NOT fire in this engine (D-05). Only five hooks fire: `on_run_start`, `on_generation_start`, `on_new_best`, `on_generation_end`, `on_run_end`.
