<objective>
Convert `parent_crossover()` to a caller-owned output-buffer API, remove the parent-cloning behavior on uncrossed pairs, fix the 1-child fallback to use `parent_2`, and delete the now-free `Mutation` clones (D-03 through D-09).

This is the core of Phase 75. Three things happen together because they all live in `parent_crossover` (`generation.rs`) and its single call site (`mod.rs`):
1. **No-crossover passthrough (D-04, D-05):** when the crossover-probability roll fails, skip the pair entirely — produce no offspring rather than cloning both parents. This is a deliberate v3.0.0 behavioral change (offspring count = crossed_pairs * 2, not all_pairs * 2). It must be documented in the PR.
2. **1-child fallback (D-06):** when multi-parent crossover returns a single child, child_2 falls back to `parent_2` (not `parent_1`) to avoid the asymmetry where both children clone parent_1.
3. **Output buffer (D-07, D-08, D-09):** `parent_crossover` takes `&mut Vec<U>`, clears it at entry, and pushes offspring into it; `mod.rs` allocates the buffer once with `Vec::with_capacity(population_size * 2)` before the loop.
4. **Mutation clone removal (D-03):** with `Mutation: Copy` from Plan 01, replace `.clone()` on mutation methods with by-value copy at `generation.rs:264,279,304` and `mod.rs:1301`.

Purpose: Eliminates the per-generation offspring `Vec` heap allocation and the two parent clones on every uncrossed pair — the largest clone reduction in the phase.
Output: New `parent_crossover` signature, a reused buffer in the generation loop, and four removed `.clone()` calls.
</objective>
