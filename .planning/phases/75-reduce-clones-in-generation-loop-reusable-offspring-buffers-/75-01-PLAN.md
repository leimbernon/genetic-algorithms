<objective>
Add `#[derive(Copy)]` to the `Mutation` enum, all 8 `*Params` payload structs, and `MutationConfiguration` (D-01, D-02). Every payload field is `Option<f64>` / `bool` / `Mutation`, all of which are `Copy`-compatible, so this is a zero-runtime-cost change that makes `Mutation` cheap to pass by value and eliminates the need for `.clone()` at every call site that copies a mutation method.

Purpose: Copy on `Mutation` is the prerequisite that lets Plan 02 delete the `mutation_method.clone()` / `configuration.mutation_configuration.method.clone()` calls (D-03) at zero cost. This plan only widens the derive set — it changes no behavior.
Output: `Mutation`, all `*Params` structs, and `MutationConfiguration` derive `Copy`.
</objective>
